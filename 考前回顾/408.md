## 红黑树插入

**规则**：
 1. 插入的节点一定为<span style="color:red;font-weight:bold;">红节点</span>
 2. 染色就是红黑互换

**插入操作**：
 1. 空树
     - 直接插入，**染色**
 2. 父**黑**
     - 直接插入
 3. <span style="color:red;font-weight:bold;">父红</span>且<span style="color:red;font-weight:bold;">叔红</span>
     - 叔父染色，祖父染色
     - 若祖父是根节点，祖父染色，否则不变
 4. <span style="color:red;font-weight:bold;">父红</span>且**叔黑**
     1. LL
         - 祖父<span style="color:red;font-weight:bold;">右旋</span>，父亲、祖父染色
     2. LR
         - 父亲<span style="color:red;font-weight:bold;">左旋</span>，父亲看作新节点，重新判断类型并调整
         - 或者和AVL一样左、右旋转，儿换爷+染色
     3. RR
         - 祖父<span style="color:red;font-weight:bold;">左旋</span>，父亲、祖父染色
     4. RL
         - 父亲<span style="color:red;font-weight:bold;">右旋</span>，父亲看作新节点，重新判断类型
         - 或者和AVL一样右、左旋转，儿换爷+染色

## 快速排序

*由于快排适用范围广，且各项效率均衡，考试涉及到排序的算法可以直接写快排代码混分*

**思想**（递归）：
 1. 选择一个元素作为枢轴povit元素（一般是表中第一个元素）
 2. 表的左右两侧设立**low**和<span style="color:red;font-weight:bold">high</span>，初始时**low**=1，<span style="color:red;font-weight:bold">high=L.length</span>
 3. <span style="color:red;font-weight:bold">high</span>指针往<span style="color:red;font-weight:bold">左</span>走，碰到比枢轴元素<span style="color:red;font-weight:bold">小</span>的就把元素放到**low**位置，然后操作**low**指针
    **low**指针往**右**走，碰到比枢轴元素**大**的就把元素放到<span style="color:red;font-weight:bold">high</span>位置，然后操作<span style="color:red;font-weight:bold">high</span>指针
     - 这里可能导致两个相同元素的相对位置发生改变，所以快排也是一种**不稳定**的排序算法
 4. 此时第一轮结束后，枢轴就到达了其最终位置，即其左侧元素均小于枢纽，而右侧元素均大于枢纽
 5. 而后，分别对其左右侧的子表进行递归的操作，直至子表中==没有元素或只有一个元素==停止，此时表中元素完全有序

*考研考察的划分操作，通常以子表的第一个元素作为枢轴对表进行划分*
**代码实现如下**：(假设数据均为int型)
```cpp
int Partition(int A[],int low,int high){
//划分操作，而正式的快排就是不断调用这个函数
	int pivot = A[low];//将当前表中第一个元素作为枢轴
	while(low<high){
		while(low < high&&A[high]>=pivot) --high;
		A[low] = A[high];//将比枢轴小的放到左边
		while(low < high&&A[low]<=pivot) ++low;
		A[high] = A[low];//将比枢轴大的放到右边
	}
	A[low] = pivot;//将枢轴元素放到最终位置
	return low;
}

//快速排序
void QuickSort(int A[],int low,int high){
	if(low < high){
		int pivotpos=Partition(A,low,high);
		//依次对两个子表进行递归的排序
		QuickSort(A,low,pivotpos-1);
		QuickSort(A,pivotpos+1,high);
	}
}
```

**知识点**：
 1. 当子表长度为1时，代码实际上会再次**调用一次**快排，但模拟时忽略了这一次调用
 2. 对一个子表调用一次快排**至少**确定一个元素的最终位置，pivot一定确认最终位置，且左边元素小于它，右边元素大于它
 3. 快排的**最好情况**是每次选择的pivot刚好可以把表分成**相对均匀**的左右两份，**最坏情况**是初始序列**基本有序**
 4. 快排递归树的树高和递归深度一致，最大递归深度为n，最小递归深度为$\log_2 n$
 5. 快排依赖**随机访问**的特性，因此适用于**顺序存储**

**做题技巧**：进行两趟快排，如果两个元素确认的最终位置，则其中**必有一个在数组边界**（2019真题）

## 最佳归并树

**结论**：
  - 对严格k叉树有$n_0=(k-1)n_k+1$，即$n_k=\dfrac{n_0-1}{k-1}$
  - 若$(n_0-1)\%(k-1)=0$，则不需要添加虚段
  - 若$(n_0-1)\%(k-1)=u\neq0$，则需要添加$k-u-1$个虚段

## CISC、RISC

| 项目       | CISC                  | RISC                      |
| -------- | --------------------- | ------------------------- |
| 指令系统     | 复杂，庞大                 | 简单精简                      |
| 指令数目     | 一般大于200条              | 一般小于100条                  |
| 指令字长     | 不固定                   | 定长                        |
| 可访存指令    | 不加限制                  | 只有LOAD和STORE指令            |
| 各种指令执行时间 | 相差较大                  | 绝大多数在一个周期内完成              |
| 各种指令使用频度 | 相差很大                  | 都比较常用                     |
| 通用寄存器数量  | 较少                    | 多                         |
| 目标代码     | 难以用优化编译<br>生成高效目标代码程序 | 采用优化的编译程序<br>生成代码**较为高效** |
| 控制方式     | 绝大多数为微程序控制            | 绝大多数为组合逻辑控制               |
| 指令流水线    | 可以通过一定方式实现            | 必须实现                      |
