# 奈奎斯特&香农定理

##### 10.27

==**奈奎斯特定理**==：对于一个**理想低通信道**（==没有噪声==、**带宽有限的信道**）
 - 其==**极限波特率**== = **2W**（单位：波特，即 码元/秒）
 - 其==**极限比特率**== = $2W\log_2{K}$ b/s

*W是信道的频率带宽（单位：Hz）*

==**香农定理**==：对于一个==**有噪声**==、**带宽有限**的信道
 - 其==**极限比特率**== = $W\log_2{(1+S/N)}$ bps
*S/N为信噪比 = $\frac{信号的功率}{噪声的功率}$*

由于在通信领域，信号功率往往比噪声功率大得多，采用**无单位记法**，信噪比会非常大
所以以**分贝dB**为单位表示信噪比：
$$信噪比 = 10\log_{10}{(S/N)}$$

例：现有两台电脑，若用一条链路将二者连接，可选的传输介质有：双绞线、同轴电缆、光纤和无线传输介质，如下：

| 链路  | 介质     | 带宽W    | 信噪比  | 备注             | S/N   |
| --- | ------ | ------ | ---- | -------------- | ----- |
| A   | 光纤     | 100MHz | 40dB | 每个码元最多取16种光强等级 | 10000 |
| B   | 同轴电缆   | 20MHz  | 30dB | 码元电平数待定        | 1000  |
| C   | UTP双绞线 | 1MHz   | 20dB |                | 100   |
| D   | 无线信道   | 20MHz  | 10dB |                | 10    |
问题：
 1. ==这些传输介质信道的抗噪能力孰强孰弱？不同传输介质在相同环境下所受的噪声功率是否相同？==
     - 抗干扰强度：A>B>C>D，事实上A>>B>STP（带屏蔽）>UTP（不带屏蔽）>D
     - **不同**，抗扰机制不同：
        - A传光，几乎不受电磁干扰，噪声来自接收机内部热噪声
        - B依靠外层屏蔽网
        - C通过双绞将两线感应的干扰相互抵消
        - STP通过在C的外再加屏蔽网，抗干扰能力进一步加强
        - D暴露在开放环境，更容易受其他电磁波的干扰
 2. ==链路B、C、D的信道最大数据传输速率各是多少？B与D带宽相同，最大数据传输速率差异说明了什么？==
     - 通过**香农定理**：$W\log_2(1+S/N)$，B、C、D=199Mb/s、6.66Mb/s、69.2Mb/s
     - 传输速率B>D，说明带宽相同的情况下，**抗噪能力强**的介质能跑出更高速率
 3. ==链路B若要达到其香农极限，每个码元需要多少种离散电平（取2的整数次幂）？==
     - 由奈奎斯特定理得：B的极限**波特率**为2W=40M码元/s
     - 反解得出一个码元应该携带：199.3/40 = 4.98 = 5 bit 信息
     - 即每个码元需要$2^5=32$种离散的电平
 4. ==链路A分别按照奈奎斯特定理和香农公式计算极限速率，说明该链路的实际瓶颈是什么？==
     - 16种光强等级 对应 每个码元携带4bit信息
     - 由**奈奎斯特定理**：极限波特率 = 200M码元/s，极限比特率 = 800Mb/s
     - 由**香农定理**：极限比特率 = $100M×log_2(1+10000) = 1.329Gb/s$
     - 实际速率取二者较小值，即800Mb/s，瓶颈在于奈奎斯特定理一边，所以想要提速只能==🟢增加带宽，或者提高调制阶数==
*注意：由第4问得出，香农极限**不一定**是最终瓶颈*

# 编码与调制技术

![[图1常见编码.png]]

**概念**：
 - 编码：二进制数据 -> 数学信号，逆过程叫**解码**
 - 调制：二进制数据 -> 模拟信号，逆过程称为**解调**

**编码技术**：
 - NRZ不归零编码：低0高1，==中不变==
 - RZ归零编码：低0高1，==中归零==
 - NRZI反向归零编码：跳0不跳1看起点，==中不变==
 - 曼彻斯特编码：跳0反跳1看中间，==中必变==（上0下1）
 - 差分曼彻斯特编码：跳0不跳1看起点，==中必变==

**调制技术**：
 - 调**幅**AM，幅移键控ASK  -- 若信号有K种**振幅**，则$1码元 = log_2K bit$
 - 调**频**FM，频移键控FSK   -- 若信号有K种**频率**，则$1码元 = log_2K bit$
 - 调**相**PM，相移键控PSK  -- 若信号有K种**相位**，则$1码元 = log_2K bit$
 - 正交幅度调制QAM
    - AM与PM结合，形成叠加信号，若有m种振幅、n种相位，则$1码元 = log_2\,mn \,bit$
    - QAM-16是采用QAM调制技术，包含16种码元

# 中继器&以太网&CSMA/CD协议

**IEEE802.3协议帧**：662n4，收发协数验
 - n：46~1500
 - 所以IEEE802.3协议帧最短：6+6+2+46+4 = 64B

**举例**：现在某岛两端各部署一台电脑，使用同轴电缆相连且
 1. 同轴电缆极限数据率为**10Mb/s**，长度不限
 2. 链路层采用**IEEE802.3协议帧**，介质访问控制采用**CSMA/CD协议**
     - 先听后发，边听边发、冲突停发
 3. 信号在同轴电缆种的传播速率为**20 0000km/s**
 4. 每个中继器对信号再生都需要时间，引入**单向时延1.2μs**
     - 电信号随着传播距离会变形，所以需要在其中插入一个中继器进行信号整形，但会引入**时间开销**
 5. 不考虑以太网帧的前导码

**问题**：
 1. ==🟣两台主机用**一根同轴电缆直连**，为保证CSMA/CD能正常工作，两台主机最远可相距多少km？==
     - A发出的第一个bit即将到达B的时候，B检测到信道空闲发送信息，此时当B的第一个bit到达A的时候，A检测到冲突，其中经过一个RTT
     - *注：即当A最后一个bit还未发出的时候，接收到了B的第一个bit，此时即为最远距离*
     - **最远距离D**：$2\times\dfrac{D}{传播速率}\leq 最小帧的传输时间$，即==D = 5120m==
 2. ==🟣若在电缆中间**插入2个中继器**，两台主机最远又可以相距多少km？为什么？==
     - 中继器是物理层设备，主要解决**信号衰减问题**，但冲突检测在链路层发生
     - 所以中继器的再生时延需要加入端到端单向时延中，并且每多个一中继器，就需要额外吞掉一个时延
     - **最远距离D**：$2\times\dfrac{D}{传播速率}+2\times 两个中继器的单向时延\leq 最小帧的传输时间$，即==D = 4640m==
     - *想要使得总距离更长，需要使用链路层设备将**冲突域**切开，将长链路分为多段，各自争用*
 3. ==🟣若该同轴电缆的标准是**10BASE5**，规格写明**单段电缆长500m**，超过就必须接一个中继器再生信号，在仍然满足CSMA/CD、且计入中继器时延的前提下，各个网段都使用500m同轴电缆，理论上这条链路最远能跨越多少m？此时用了几个中继器、分成几个网段？==
    - 10Base5 --- 10Mbps，同轴电缆，最远传输500m
    - 假设有n个中继器，网段数k=n+1，此时
      $$2\times\dfrac{500}{传播速率}(n+1)+2\times n个中继器的单向时延\leq 最小帧的传输时间$$
    - ==得出n≤6.4，取整得出n=6，所以最远跨越 (6+1)×500=3500m，共计**7个**网段==

**衍生知识点**：802.3标准给出10BASE5的 5-4-3理论
 - 5 -- 5个网段
 - 4 -- 4个中继器
 - 3 -- 其中只有3个网段可以挂载设备，剩余2个只能当纯链路使用
 - 所以上述第3问，实际最大长度被锁在 ==5×500m = 2500m==

# 集线器

CSMA/CD**协议要点**
 - 先听后发，边听边发，**冲突停发**，**随机重发**
 - 如何随机重发
    - **截断二进制指数退避算法**：
       - 随机等待一段时间 = r 倍**争用期**，其中 r 是随机数（**争用期**是一段固定大小的时间）
         1. 如果 k ≤ 10，在$[0,(2^k-1)]$区间随机取一个整数r
         2. 如果 k > 10，在$[0,(2^{10}-1)]$区间随机取一个整数r
 - **特别注意**
    - **第10次**冲突是随机重发的分水岭
    - **第16次**冲突，直接躺平，放弃传帧，报告上级（网络层）


**举例** 若目前有4个人在岛上打游戏，使用**集线器Hub**将4台电脑连接，但==集线器不隔离冲突域，4台主机共享一条总线，**冲突**导致MAC帧发送不出去==

**前置条件**：
 1. 4台主机连接在同一集线器上，处于**同一个冲突域**，半双工工作，采用CSMA/CD
 2. 局域网为**10BASE-T**以太网，数据率为**10Mb/s**，**争用期**为**51.2μs**

**问题**：
 1. ==🟣A发送某个帧时连续发生了**3次碰撞**，第3次碰撞后，重传该帧前**最长**要等待多少μs？**最短**又需要等待多少μs？==
     - 3次碰撞，整数$r\in[0,2^3-1=7]$
     - 即最长等待7×争用期51.2 = 358.4μs，最短等待0
 2. ==🟣B运气极差，同一帧连续发生**12次**碰撞，第12次碰撞后，他重传前的**最长**等待时间是多久？==
     - 12次碰撞，整数$r\in[0,2^{10}-1=1023]$
     - 即最长等待 1023 × 51.2 = 52.3776ms
 3. ==🟣若该帧一直碰撞，网卡最终会如何处理？==
     - 若一直碰撞，碰撞到16次，重传16次失败后，就丢弃该帧，并向高层报告
 4. ==🟣为什么退避时间要以**争用期**为单位，且随机范围以**指数增长**？==
     - **以争用期为单位**：争用期是确保自身未碰撞的最小时间粒度，若退避时间小于争用期，两个窗口可能在彼此未发现对方时，再次发送
     - **指数增长**：冲突越多，说明同时争用的站越多，负载越重，需要更长的时间去降低冲突概率

*注：退避结束 ≠ 立即发送，仍需要持续监听信道，忙则继续等待*

        - 目的MAC = 本机MAC（单播命中）
        - 目的MAC = 广播地址 FF:FF:FF:FF:FF:FF
        - 目的MAC = 组播地址（且本机已加入该组）

# 停止-等待、后退N帧、选择重传协议

**举例**：在使用交换机之后，现在又引入**卫星通信**，岛上的**地面站P（用户端）**，对端是某ISP的**地面站Q（网关站）**，由于链路使用的是**停止-等待协议**：==发1个数据帧 -> 等待ACK -> 再发下一个==（发送时延忽略不计）

还有两个卫星接入卡可选
 - 低轨卫星链路：H1 = 550km
 - 高轨卫星链路：H2 = 36000km

![[图3链路层卫星链路.png]]

**前提条件**：
 1. 卫星无线信道带宽为**20MHz**，信噪比**31**，电磁波传播速度$c = 3\times 10^8m/s$
 2. P、Q都在卫星通信范围内，为简化计算，P-卫星、卫星-Q的距离均为离地高度H
 3. **卫星的作用本质是物理层的中继器**，将P、Q的电磁波信号整形后重新发出
 4. 帧长**1500B**，帧序号字段**6bit**，ACK帧的发送时延忽略不计
 5. 忽略处理时延与排队时延，且链路**不会误码、不会丢帧**
 6. 两张接入卡分别对应H1和H2

**问题**：
 1. ==🟣用**香农定理**计算该无线信道的最大传输速率R，并在后续各问中将其作为链路速率？==
     - $R = W\log_2(1+S/N) = 20 \times 10^6 \times \log_232 = 20\times 10^6\times5=100Mb/s$
 2. ==🟣用H表示卫星高度，c表示电磁波传输速率：计算数据帧从P经过卫星到达Q的**单向传播时延Tp**？以及数据帧与其ACK的**往返传播时延RTT**？分别带入H1、H2计算具体值==
     - 单向传播时延$Tp = \dfrac{2H}{c}$
        - 低轨 = 3.67ms
        - 高轨 = 240ms
     - 往返传播时延$RTT = 2Tp$
        - 低轨 = 7.33ms
        - 高轨 = 480ms
 3. ==🟣现在链路层用的是**停止-等待协议**，先用H，C，L（数据帧长度），R（链路速率）列式，再分别带入H1，H2：==
     - 首先是计算**单数据帧**发送时延$Tt=\dfrac{L}{R}=\dfrac{1500\times8}{100\times10^6}=0.12ms$
     1. ==🔵停止-等待协议的信道利用率U与有效数据传输速率S？==
         - $U_{SW}=\dfrac{Tt}{Tt+RTT},S_{SW}=R·U_{SW}$
         - 低轨：U = 1.61%，S = 1.61Mb/s
         - 高轨：U = 0.025%，S = 25.0Kb/s
     2. ==🔵改用**GBN**后，本题序号字段允许的最大发送窗口是多少？取最大窗口时的信道利用率与有效数据传输速率==
         - **分析**：GBN接收窗口大小固定为1，使用6bit编号，由$发送窗口+接收窗口\leq 2^6=64$，得**发送窗口N=63**
         - $U_{GBN}=\min\{1,\dfrac{N·Tt}{Tt+RTT}\},S_{GBN}=R·U_{GBN}$
         - 低轨：U = 1.011 -> 100%，即 S = 100Mb/s
         - 高轨：U = 1.575%，S = 1.575Mb/s
     3. ==🔵改用**SR**后，本题序号字段允许的最大发送窗口是多少？最大信道利用率与有效数据传输速率是多少？==
         - **分析**：由于SR发生窗口和接收窗口**不定长**，且本题规定二者相同，则**发送窗口 = 接收窗口 = 32 = N**
         - $U_{SR}=\min\{1,\dfrac{N·Tt}{Tt+RTT}\},S_{SR}=R·U_{SR}$
         - 低轨：U = 51.52%，S = 51.52Mb/s
         - 高轨：U = 0.80%，S = 0.800Mb/s
 4. ==🟣简答：==
     1. ==🔵两张卡应该插哪一张、配哪一个滑动窗口协议？列表比较==
         - 应该插入低轨卡，且使用GBN协议
         - 因为只有低轨GBN可以将链路带宽（100Mb/s）吃满
     2. ==🔵卫星飞得高度，是否会直接拉低无线信道的最大传输速率？==
         - **不会**改变信道速率，香农定理只与**带宽和信噪比**有关，两种高度的信道容量都是100Mb/s
         - 但是高度拉长了**RTT**，从而降低了**信道利用率**
     3. ==🔵为什么信道速率相同，高轨链路却需要更大的发送窗口？要分别把两条链路填满，窗口至少应该多大？==
         - 高轨链路需要更多的窗口去填满Tt+RTT，即$Tt\times N=Tt+RTT$
         - 低轨：N = 63
         - 高轨：N = 4001，即需要使用12bit给帧编号

*注意：上述结论**并非**说明GBN**优于**SR，一旦发生丢帧的现象，GBN就需要退回重传，反而效率不如SR*

     - RTS/CTS

     - RTS：Request To Send请求发送
     - CTS：Clear To Send允许发送
 4. ==🟣802.11帧首部中的Duration（持续期）字段表示什么含义？在本题的RTS、CTS、DATA和ACK帧中该字段分别如何使用？==
     - Duration：从当前帧发送完毕开始，到本次完整帧交换结束，还需要占用信道的时间

     - CTS：CTS发送完毕之后剩余的时间
     - DATA：DATA发送完毕之后剩余的时间
     - ACK：本次通信结束，0

## 问题5：注意什么时候直接发送，什么时候随机退避

分析以下情况

**情况1**：一开始是空闲的
手机X准备发送RTS时，检测到物理信道空闲且NAV为0
 1. ==🟣X是否需要随机退避？
     - 不需要进行随机退避，只需等待DIFS，若空闲则直接发送RTS
     - DIFS必须持续监听，若期间重新变忙，则这个DIFS报废，需重新计时等待一个完整的DIFS
 2. ==🟣X应该在什么条件下发送RTS？
     - 在持续监听一个完整的DIFS之后，发送RTS

**情况2**：一开始忙碌
手机X准备发送RTS时，检测到A的手机Y正在使用信道
Y发送完毕后，X持续监听信道空闲DIFS，并随机选择退避计数器：==**K=5**==
退避倒计时经过2个空闲时隙后，B的手机Z又抢占了信道，于是X冻结退避计数器
假设**Z的通信结束**、X的**NAV归零**后，物理信道**持续空闲**
**回答**：
 1. ==🟣X的退避计数器冻结为多少？==
     - K = 3
 2. ==🟣NAV归零后，X能否立即继续递减退避计数器？==
     - 不能，需要持续监听一个DIFS，若空闲则继续递减计数器
 3. ==🟣从NAV归零且物理信道转为空闲开始，还要经过多长时间，X才能发送RTS？==
     - DIFS + K × 空闲时隙 = 188μs
 4. ==🟣X是否需要重新随机选择退避计数器？==
     - 不需要
 5. ==🟣X的竞争窗口是否需要翻倍？==
     - 不需要
        - 退避计数器只是冻结
        - 被其他站点抢先不代表X发送失败
        - 只有X尝试发送之后，没有收到CTS或者ACK，才说明发送失败，需要扩大竞争窗口并重新退避

## 问题6：RTS/CTS到底值不值得？
假设手机X准备发送时，物理信道空闲且NAV为0，X持续监听信道空闲DIFS后直接发送，不进行随机退避，并且本次发送一次成功
 1. ==🟣启用RTS/CTS时，计算从开始监听DIFS到收到ACK的总时间？==
     - DIFS + RTS + SIFS + CTS + SIFS + DATA + STFS + ACK = 469μs
 2. ==🟣关闭RTS/CTS时，计算从开始监听DIFS到收到ACK的总时间？==
     - DIFS + DATA + SIFS + ACK = 408μs
 3. ==🟣RTS/CTS为本次成功发送增加了多少时间开销？==
     - 469 - 408 = 61μs
 4. ==🟣既然RTS/CTS会增加时间开销，为什么在存在隐藏站且DATA帧较长时仍然值得使用？==
     - 若存在隐藏站的话：
        - 发生碰撞时，主要损失的是发送时延很短的RTS，而不是较长的DATA
        - AP发送CTS后，隐藏站能够根据Duration设置NAV
        - DATA帧越长，DATA碰撞造成的浪费越大
        - 隐藏站越多，RTS/CTS降低碰撞的价值越明显
*短帧、竞争较少时，可能不需要开启RTS/CTS功能*

## 选择题

正确率：

### 物理层

**知识点**：
 1. 数据转换为模拟信号为**调制**，转换为数字信号为**编码**
 2. 将模拟信号转换为数字信号的时候，为了**无失真**的恢复原始模拟信号，采样率必须大于等于信号最高频率的**两倍**
 3. **物理层特性**：
     - **机械特性**：定义物理连接的边界点。即接插装置，指明接口所用的接线器的形状和尺寸、引脚数目和排列、固定和锁定装置等
     - **电气特性**：规定物理连接上，线路上信号的电压高低、阻抗匹配、传输速率和距离限制
     - **功能特性**：物理接口各条信号线的用法
     - **规程特性**：定义各条物理线路的工作规程和时序关系

### 数据链路层

**知识点**：
