已知：
 1. H0：MAC = AA:BB:CC:DD:EE:00，尚无IP
 2. DHCP服务器：IP = 166.1.0.9/17，MAC = AA:BB:CC:DD:EE:09
 3. 默认网关：166.1.0.5
 4. 已占用地址：H1 = 166.1.0.1，H2 = 166.1.4.2
 5. 服务器决定向H0分配166.1.0.10

**新主机接入网络**：DHCP过程，以应届生求职为例
 1. 发现报文
     - 海投简历
     - **广播**
 2. 提供报文
     - 决定录用（OFFER），公司分配一个岗位
     - 包含：租期、默认网关IP、子网掩码、默认DNS IP
     - **一对一单播**
 3. 请求报文
     - **确认**OFFER，让其他公司知晓，已有OFFER（因为局域网内可能有多个DHCP）
     - 若此时有其他DHCP服务器之前分配过IP地址，在收到此报文后，会解冻分配的IP地址，并将其分给其他人
     - **广播**
 4. 回复报文
     - 签工作合同
     - **一对一单播**

     - 源/目的端口（传输层）

	     - 提供报文：67，68

	     - 请求报文：0.0.0.0，255.255.255.255

 7. ==🟣为什么DHCP不能基于TCP？==
     - H0没有IP地址，所以DHCP必须基于UDP协议

| 阶段  | 链路层收          | 网络层收          | 传输层收 |
| --- | ------------- | ------------- | ---- |
| 发现  | H1、H2、B3、DHCP | H1、H2、B3、DHCP | DHCP |
| 提供  | H0            | H0            | H0   |
| 请求  | H1、H2、B3、DHCP | H1、H2、B3、DHCP | DHCP |
| 回复  | H0            | H0            | H0   |

*B3是一个路由器，但它不会把255.255.255.255洪泛出去，所以路由器可以隔离广播域*
