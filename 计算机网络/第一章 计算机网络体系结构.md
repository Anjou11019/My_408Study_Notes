# 计算机网络的概念

##### 5.20

**计算机网络**（Computer Networking）是一个将众多**分散的、自治的**计算机系统，通过**通信设备**与**线路**连接起来，由功能完善的**软件**实现**功能共享**和**信息传递**的系统

## 计算机网络、互连网、互联网的区别

计算机网络（简称网络）：由若干个**结点（node）** 和连接这些结点的**链路（link）** 组成
 - 结点可以是计算机、集线器、交换机、路由器
 - 链路可以是有线链路、无线链路

**集线器（HUB）**：
 - 可以把**多个结点连接起来**，组成一个计算机网络
 - 会产生数据冲突
 - 集线器工作在**物理层**

**交换机（Switch）**：
 - 可以把**多个结点连接起来**，组成一个计算机网络
 - 不会产生数据冲突
 - 交换机工作在**数据链路层**

**路由器（Router）**：
 - 可以把**两个或者多个计算机网络互相连接起来**，形成规模更大的计算机网络，也叫**互连网**
 - 路由器工作在**网络层**
*计网课程中的路由器和家用路由器有一些区别。家用路由器 = 路由器+交换机 + 其他功能*

**ISP**（Internet Service Provider），即互连网服务提供商（中国电信、中国移动、中国联通）
**互联网**（因特网，Internet）：
 - 由各大ISP和国际机构组建，覆盖全球范围的互连网（internet）
 - **互联网**必须使用**TCP/IP协议**通信，互连网可以使用**任意协议**通信

## 计算机网络的组成和功能

### 计算机网络的组成

**从组成部分来看**：计算机网络包含**硬件、软件、协议**
 - **硬件**：主要由主机，即**端系统（end system）** 、通信设备、通信链路组成
 - **软件**：方便用户使用，实现资源共享
 - **协议**：
    - 规定计算机网络中的通信规则
    - 由硬件、软件共同实现

**从工作方式来看**：计算机网络分为**边缘部分、核心部分**
 - **边缘部分**：
    - 工作方式：直接为用户服务
    - 主要由连接到互联网上的主机及其软件组成
 - **核心部分**：
    - 工作方式：为边缘部分提供服务（**连通性、交换服务**）
    - 由大量网络和连接这些网络的路由器组成

**从逻辑功能来看**：计算机网络由**资源子网和通信子网**组成
 - 资源子网：
    - 计算机网络中运行应用程序，向用户提供可共享的硬件、软件和信息资源部分
    - 主要由连接到互联网上的**主机**组成
 - **通信子网**：
    - 计算机网络中负责计算机间信息传输的部分。即把计算机和其他用户装置互连在一起的**所有通信设备和介质**的总称
    - 主要由 通信链路+通信设备+协议 构成
    - *主机内部实现信息传输的网络适配器、底层协议 属于通信子网的范畴*

### 计算机网络的功能

**数据通信**：实现计算机之间数据传输。是**最基本、最重要的功能**

**资源共享**：
 - **硬件资源共享**：智能音箱等智能设备请求服务器服务
 - **软件资源共享**：从应用商店下载软件等
 - **数据资源共享**：分享视频等

**分布式处理**：将复杂任务分派给网络中的多台计算机

**提高可靠性**：网络中各台计算机互为替代机（比如网盘服务器集群网络）

**负载均衡**：网络中各台计算机共同分担繁重工作（某游戏用多台服务器均衡处理玩家请求）

其他：满足社会需求、生活需求（远程办公、远程教育、娱乐等）

## 电路交换、报文交换、分组交换

### 电路交换

**电路交换**（Circuit Switching）：通过物理线路的连接，**动态的分配传输线路资源**

**优点**：
 - 通信前从主叫端建立一条**专用的物理通路**，在通信的全部时间内，两个用户**始终占用**端到端的**线路资源**
 - 数据直通，**传输效率高**

**缺点**：
 - 建立/释放连接，**需要额外的时间开销**
 - 线路被通信双方**独占**。**利用率低**
 - 线路分配的**灵活性差**
 - 交换结点**不支持差错控制**

**总结**：更适用于低频次、大量的传输数据，然而计算机之间数据传输往往是**突发式**的，会**高频、少量**的传输数据

### 报文交换

采用**报文交换**技术

==存储转发==的思想：把传送的数据单元先**存储**进中间结点，在根据目的地址**转发**至下一结点

**优点**：
 - 通信前**无需建立连接**
 - 数据以**报文**为单位被交换结点间**存储转发**，通信线路**可以灵活分配**
 - 通信时间内，两个用户**无需独占**一整条物理线路。相比于电路交换，**线路利用率高**

**缺点**：
 - **报文不定长**，==不方便存储转发管理==
 - 长报文的存储转发**时间开销大**、**缓存开销大**
 - 长报文容易出错，重传代价高

### 分组交换

**分组**（Packet）：**定长的**，首部+数据
 - **首部**：即分组的控制信息，包含：源地址、目的地址；**分组号**等

**优点**：
 - 通信前**无需建立连接**
 - 数据以**分组**为单位被交换结点间**存储转发**，通信线路**可以灵活分配**
 - 通信时间内，两个用户**无需独占**一整条物理线路。相比于电路交换，**线路利用率高**
 - 交换结点**支持差错控制**（通过校验技术）

==相比于报文交换==，分组交换改进了如下：
 - 分组定长，方便存储转发管理
 - 分组的存储转发时间开销小、缓存开销小
 - 分组不易出错，重传代价低

**缺点**：
 - 相比于报文交换，**控制信息占比增加**
 - 相比于电路交换，依然**存在存储转发时延**
 - 报文被拆分成多个分组，传输过程中可能出现失序、丢失等问题，**增加处理的复杂度**

### 性能分析

|               | 电路交换            | 报文交换 | 分组交换        |
| ------------- | --------------- | ---- | ----------- |
| 完成传输所需时间      | 最少（排除建立/释放连接耗时） | 最多   | 较少          |
| 存储转发时延        | 无               | 较高   | 较低          |
| 通信前是否需要建立连接   | 是               | 否    | 否           |
| 缓存开销          | 无               | 高    | 低           |
| 是否支持**差错控制**？ | 不支持             | 支持   | 支持          |
| 报文数据有序到达？     | 是               | 是    | 否           |
| 是否需要额外的控制信息？  | 否               | 是    | 是（控制信息占比最大） |
| 线路分配灵活性       | 不灵活             | 灵活   | 非常灵活        |
| 线路利用率         | 低               | 高    | 非常高         |

## 计算机网络的分类

**分布范围分类**：
 - **广域网WAN**（Wide Area Network）
    - 范围：几十~几千公里
    - 跨省/跨州/跨国
 - **城域网MAN**（Metropolitan Area Network）
    - 范围：几~几十千米
    - 通信技术：常采用以太网技术，所以通常纳入局域网讨论
 - **局域网LAN**（Local Area Network）
    - 范围：几十米~几千米
    - 通信技术：以太网技术
 - **个域网PAN**（Personal Area Network）
    - 范围：几十米
    - 通常是通过无线技术将个人设备连接起来的网络，因此也常称为无线个域网
*目前局域网几乎都采用以太网技术，因此以太网几乎成为局域网的代名词*

**传输技术分类**：
 - **广播式网络**：当一台计算机发送数据分组时，广播范围内所有计算机都会收到该分组，并通过**检查分组的目的地址**决定是否接收该分组
    - 所有无线网都是广播网
 - **点对点网络**：数据只会从发送方点对点发到接收放，精准送达
    - 比如路由器转发的数据分组

**拓扑结构分类**：
 - **总线型结构**：
    - 数据广播式传输
    - 存在**总线争用**问题
    - 典型设备：集线器连接的设备
 - **环形结构**：
    - 数据广播式传输
    - 通过**令牌**解决总线争用问题，令牌顺环形依次传递，拿到令牌者可使用总线
    - 典型代表：令牌环网
 - **星型结构**：
    - 由中央设备实现数据的**点对点传输**
    - 不存在总线争用问题
    - 典型设备：以太网交换机连接的设备
 - **网状结构**:
    - 数据传输通过各中间结点逐一存储转发
    - **属于点对点传输**
    - 典型代表：由众多路由器构建的广域网

**使用者分类**：
 - **公用网**：向公众开放的网络
 - **专用网**：仅供某个组织内部使用的网络

**传输介质分类**：
 - **有线网络**
 - **无线网络**

## 计算机网络的性能指标

### 性能指标1：速率

**信道（Channel）**：表示向某一方向传送**信息的通道**，一条通信线路在逻辑上往往对应一条**发送信道**和一条**接收信道**

**速率（Speed）**：指连接到网络上的节点在信道上传输数据的速率。也叫**数据率**或**比特率**、==**数据传输速率**==

**单位**：bit/s，b/s，**bps**（bit per second）
 - 1B = 8bit
 - **数量前缀**：K($10^3$) -> M($10^6$) -> G($10^9$) -> T($10^{12}$) 

*在计组和操作系统中：**数量前缀**K($2^{10} = 1024$) -> M($2^{20}$) -> G($2^{30}$) -> T($2^{40}$) *

### 性能指标2：带宽

**带宽**（bandwidth）：某信道所能传输的**最高数据率**

==节点间通信实际能达到的最高速率，由**带宽、节点性能**共同限制==

*在《通信原理》中：带宽表示某信道==允许通过的信号频带范围==（单位：Hz）*

本质：==信道带宽越大，传输数据的能力越强==
 - 两种解释的带宽，通过**香农定理**和**奈氏准则**联系起来

### 性能指标3：吞吐量

**吞吐量**（Throughput）：指**单位时间**内通过某个网络（信道、接口）的**实际数据量**
 - 吞吐量受带宽限制、受复杂的网络负载情况影响


### 性能指标4：时延

**时延**（Delay）：指数据从网络的**一端传输到另外一端所需的时间**。有时也叫延迟或者迟延
 - **发送时延**：
    - **传输时延**：节点将数据推向信道所花费的时间
 - **传播时延**：
    - 电磁波在信道中传播一定距离所花费的时间
 - **处理时延**：
    - 被路由器处理所花费的时间
 - **排队时延**：
    - 数据排队进入、排队发出路由器所花费的时间
$$ 发送时延 = \frac{数据长度bit}{发送速率bit/s}$$
$$传播时延 = \frac{信道长度m}{电磁波在信道中的传播速度m/s}$$
$$总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延$$

### 性能指标5：时延带宽积

==**时延带宽积** = 传播时延 × 带宽== bit

**时延带宽积的含义**：一条链路中，**已经**从发送端**发出但尚未到达**接收端的**最大比特数**
- 时延带宽积用于设计**最短帧长**（后续学习）

### 性能指标6：往返时延

**往返时延RTT**（Round-Trip Time）：表示从发送方**发送完数据**，到发送方**收到来自接收方的确认**总共经历的时间

*打游戏时的游戏延迟，反映的就是PC-服务器之间的**往返时延RTT***

### 性能指标7：信道利用率

**信道利用率**：某个信道有百分之多少的时间是有数据通过的
$$ 信道利用率 = \frac{有数据通过的时间}{有数据通过的时间+没有数据通过的时间}$$

# 计算机网络体系结构与参考模型

## 分层的设计思想

对于两个快递终点站A、B之间，会有若干中转站C、D、E进行中转
快递网络就是一个非常复杂的系统，其**需要完成的功能有**：
 - 货物打包
 - 取件、派件
 - 冷链存储
 - 包裹路由
 - 包裹运输
 - ……

对于终点站而言可分为4层：运输部门、仓库部门、快递员、顾客

**分层设计思想**：将庞大复杂的问题，转化为若干较小的局部问题

计算机网络是一个非常复杂的系统，要完成**诸多功能**：
 - **差错控制**：确保数据在传输过程中不会出错
 - **流量控制**：发送端的发送速率必须使接收端来得及接收
 - **分段和重装**：发送端将发送的数据块划分为更小的单位，并在接收端将其还原
 - **复用和分用**：发送端几个高层会话复用一条低层的连接，在接收端在进行分用
 - **连接建立和释放**：交换数据前先建立一条逻辑连接，数据传送结束后释放连接
 - ……
## 计算机网络的分层结构

将复杂的计算机网络在逻辑上划分为多个层次，并将各种功能安排在合适的层次中

不同类型的节点，==实现的功能层次可能不一样==

分层结构的设计并**不唯一**，可以根据实际需求增加或减少层次
==同一个功能==可以在多个层次中重复出现

### 三种常见的计算机网络体系结构

*综合前两者，便于学习和理解计算机网络*

### 网络体系结构的概念

**网络的体系结构**（Network Architecture）是计算机网络的各层及其协议的**集合**，就是这个计算机网络及其构件所应完成的**功能的精确定义（不涉及实现）**

**实现**（implementation）是遵循这种体系结构的前提下，用何种硬件或软件完成这些功能的问题

==体系结构是**抽象**的，而实现则是**具体**的==

#### 各层之间的关系

**水平关系**：
 - **实体**：在计算机网络的分层结构中，第n层中的活动元素（软件+硬件）通常称为第n层实体。不同机器上的同一层称为**对等层**，同一层的实体称为**对等实体**
 - **协议**：即网络协议（Network Protocol），是控制==对等实体之间==进行通信的规则的集合，是**水平的**

**垂直关系**：
 - **接口**：即同一节点内***相邻两层的实体***交换信息的逻辑接口，又叫做**服务访问点**（Service Access Point，SAP）
 - **服务**：服务指***下层为紧邻的上层***提供的功能调用，它是**垂直的**

#### 数据的传输过程（水平）

在用户看来，数据似乎是被原模原样传输的
 - 用户感知不到数据被压缩、解压的过程

那么假设在应用层有一种YSCS（压缩传输）协议
 - 发送方将数据压缩后，需要增加首部，说明==采用了哪种压缩算法==
 - 接收方==根据首部信息选择解压缩算法==将数据解压
 - ……
*首部的大小、具体格式要在协议中明确规定*

**为什么要分层？为什么要制定协议**
 - 计算机网络功能复杂
 - 采用分层结构，将诸多功能合理的划分在不同层次
 - 对等层之间制定协议，以实现功能

#### 数据的传输过程（垂直）

**过程**：
 - 数据
 - **应用层首部**+数据
 - **传输层首部**+应用层首部+数据
 - **网络层首部**+传输层首部+应用层首部+数据
 - **链路层首部**+网络层首部+传输层首部+应用层首部+数据+**链路层尾部**
 - **比特流**（物理层）

### PDU、SDU、PCI的概念

**协议数据单元PDU**（Protocol Data Unit）：对等层次之间传送的数据单位，第n层的PDU记作n-PDU

**服务数据单元SDU**（Service Data Unit）：为完成上一层实体所要求的功能而传送的数据。第n层的SDU记作n-SDU

**协议控制信息PCI**（Protocol Control Information）：控制协议操作的信息。第n层的PCI记作n-PCI

**总结**：n-SDU + n-PCI = n-PDU = （n-1）-SDU

### 协议的三要素

协议由**语法、语义和同步**三部分组成：
 - **语法**
    - 数据与控制信息的格式。例如，协议控制信息部分占几个字节、每个字节什么含义；协议的数据部分最多由多少字节
 - **语义**
    - 需要发出何种控制信息、完成何种动作及做出何种回答。例如，协议中需要明确规定：发送方发完数据后，接收方是否需要应答，以及应答的种类有哪些
 - **同步（时序）**
    - 执行各种操作的条件、时序关系等，即事件实现顺序的详细说明。例如，发送方发完数据后，接收方需要立刻应答。如果发送方在10s内未收到传输成功应答，则发送方会再次发送数据

## OSI参考模型

**OSI参考模型（从下至上）
 1. **物理层**Physical Layer
 2. **数据链路层**Data Link Layer
 3. **网络层**Network Layer
 4. **传输层**Transport Layer
 5. **会话层**Session Layer
 6. **表示层**Presentation Layer
 7. **应用层**Application Layer

*TCP/IP模型第二次为Internet Layer，经常翻译为网际层，OSI第三层为Network Layer，常翻译为网络层。考研中通常使用后者*

**常见网络设备的功能层次**：
 - **集线器**：1
 - **交换机**：1、2
 - **路由器**：1、2、3

### 物理层

**任务**：实现相邻节点之间的**比特的传输**
 1. 需定义电路接口参数（如形状、尺寸、引脚数等）
 2. 需定义传输信号的含义、电气特征（比如：5V代表1；每比特信号持续0.1ms）

### 数据链路层

**任务**：确保相邻节点之间的链路**逻辑上无差错
 1. ==**差错控制（最主要）**==：检查+纠错；或检错+丢弃+重传
 2. **流量控制**：协调两个节点之间发送帧Frame的速率

*通过帧Frame（包含多个比特）传输，并使用校验码技术*

### 网络层

**任务**：**把分组从源结点转发到目的结点**
 1. **路由选择**：构造并维护路由表，决定分组到达目的节点的最佳路径
 2. **分组转发**：将分组从合适的端口转发出去
 3. 拥塞控制：发现网络拥塞，并采取措施缓解拥塞
 4. 网际互连：实现异构网络互联
 5. 其他功能：差错控制、流量控制、连接建立与释放、可靠传输管理（以**分组**为单位实现）

*网络层的对等实体之间以**分组Packet（数据报）** 为单位将数据转发出去*

*数据链路层只能保证==**帧**局部正确==，而网络层需要保证==**分组**全局正确==*

### 传输层

**任务**：实现**端到端**通信，即实现进程到进程的通信；**端**指==端口==
 - **复用和分用**：发送端几个高层实体复用一条低层的连接，在接收端再进行分用
 - 其他功能：差错控制、流量控制、连接建立与释放、可靠传输管理（以**报文段**为单位实现）

*传输层与传输层之间以**报文段Segment**为单位传输数据*

### 会话层、表示层、应用层

**会话层任务**：管理进程间会话
- **会话管理**：采用==检查点机制==，当通信失效时从检查点继续恢复通信

**表示层任务**：解决不同主机上信息表示不一致的问题
 - **数据格式转换**：如编码转换、压缩解压、加密解密

**应用层任务**：实现特定的网络应用
 - 功能繁多

### 总结：各层数据传输单位

**数据传输单位**：
 - **应用层**：==报文Message==
 - **传输层**：==报文段Segment==
 - **网络层**：==分组Packet==
 - **数据链路层**：==帧Frame==
 - **物理层**：==比特bit==

*越往上层数据单位越大*

| OSI模型    | 任务                | 功能                                               | 传输单位          |
| -------- | ----------------- | ------------------------------------------------ | ------------- |
| #7 应用层   | 实现特定网络应用          | 略                                                | 报文Message     |
| #6 表示层   | 解决不同主机上信息表示不一致问题  | **数据格式转换**                                       |               |
| #5 会话层   | 管理进程间会话           | **会话管理**                                         |               |
| #4 传输层   | 实现端到端通信           | **复用和分用**、差错控制、流量控制、连接建立与释放、可靠传输管理               | 报文段Segment    |
| #3 网络层   | 把分组从源节点转发到目的节点    | **路由选择**、分组转发、拥塞控制、网际互连、差错控制、流量控制、连接建立与释放、可靠传输管理 | 数据报（分组）Packet |
| #2 数据链路层 | 确保相邻节点之间的链路逻辑上无差错 | **差错控制**、流量控制                                    | 帧Frame        |

##### 5.22
## TCP/IP模型

**参考模型**：
 1. **网络接口层**：物理层+数据链路层
 2. **网络层**
 3. **传输层**
 4. **应用层**：会话层、表示层、应用层

**OSI参考模型的问题**：
 - 并不是所有网络应用都需要**数据格式转换（表示层）和会话管理功能（会话层）** 
 - 对于数据链路层和物理层，由于网络硬件种类繁多，不应该有过多限制
 - 数据的局部正确 **不能推出** 数据的全局正确

### 应用层

TCP/IP理念：如果某些应用需要数据格式转换、会话管理等功能，就交给应用层的特定协议去实现

### 网络接口层

**任务**：实现相邻节点之间的数据传送（为网络层传输分组），但**具体怎么传输不做规定**
 - 使得TCP/IP网络体系结构具有**更强的灵活性、适应性**

### 网络层

**任务**：只保证**尽最大能力交付**，数据传输是**不可靠的**

**功能**：**路由选择、分组转发、** 拥塞控制、网际互连
 - **去除**了差错控制、流量控制、连接建立与释放、可靠传输管理

网络接口层不完全可靠，因此网络接口层接收到的分组有可能有差错

### 传输层

**功能**：**复用和分用**、==差错控制、流量控制、连接建立与释放、可靠传输管理==
 - 在接收段对**全局数据**进行差错控制、流量控制、连接建立与释放、可靠传输管理

数据传输的正确、可靠性由传输层负责，压力给到**网络边缘部分（主机）**

### 总结

| TCP/IP模型 | 任务                | 功能                             |
| -------- | ----------------- | ------------------------------ |
| #4 应用层   | 实现特定网络应用          | 略                              |
| #3 传输层   | 实现端到端通信           | 复用和分用、差错控制、流量控制、连接建立与释放、可靠传输管理 |
| #2 网络层   | 把分组从源节点转发到目的节点    | 路由选择、分组转发、拥塞控制、网际互连            |
| #1 网络接口层 | **实现相邻节点之间的数据传送** | 无具体规定                          |
*OSI网络层可向上层提供：*
 - 有连接可靠的服务（虚电路）
 - 无连接不可靠的服务（数据报）

*TCP/IP网络层仅向上提供*
 - 无连接不可靠的服务（数据报）

*OSI传输层仅向上层提供*
 - 有连接可靠的服务

*TCP/IP传输层可向上层提供*
 - 有连接可靠的服务 **TCP协议**
 - 无连接不可靠的服务 **UDP协议**
