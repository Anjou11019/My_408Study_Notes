# 通信基础

##### 5.25

**物理层**主要任务：实现相邻节点之间==比特的传输==

## 通信基础的基本概念

### 信源、信宿、信号、信道

**信源**：信号的来源（即数据的发送方）

**信宿**：信号的“归宿”（即数据接收方）

**数据**：即信息的实体，在计算机内部数据通常是二进制

**信道**：信号的通道
 - 通常而言：一条物理线路通常包含两条信道，即**发送信道、接收信道**

**信号**：数据的载体
 - **数字信号**：信号值是**离散的**（信号值y{0,1}）
 - **模拟信号**：信号值是**连续的**（信号值y(0,1)）

### 码元

假设：信号周期 T = 1秒，在一个信号周期内，有可能出现==2种信号==，每种信号对应一个==二进制数==，也有可能出现==4种信号==，每种信号对应一个==4进制数==
 - 每一个信号就是一个**码元**
 - 可以把信号周期称为**码元宽度**

**优点**：每个信号周期内可以传输更多的信息。换而言之每个码元可以携带更多信息
 - **代价**：需要加强信号的功率，并且对信道的要求更高

*如果一个码元可能有4种状态，那么可以称其为**4进制码元***

**码元和比特的关系**： 
如果一个**周期**内可能出现**K种信号**则
$$1码元 = \log_2{K}bit$$

### 速率

**波特率**：每秒传输几个码元
 - 单位：**码元/秒**，或**波特**（Baud）

比特率：每秒传输几个比特
 - 单位：bit/s，或b/s，bps

*如果一个码元携带n比特的信息量，则波特率M Baud对应的比特率为 Mn b/s*

## 信道的极限容量

**带宽**：
 - 计网中：表示某信道能通过的**最高数据率**
 - 通信原理中：表示某信道**允许通过的信号频带范围**
**香农定理和奈氏准则**解释二者之间的内在联系
### 噪声

**信号**：是数据的载体，在信道上传输

**噪声**：对信道产生干扰，影响信道的数据传输效率

### 奈奎斯特定理（奈氏准则）

==**奈奎斯特定理**==：对于一个**理想低通信道**（==没有噪声==、**带宽有限的信道**）
 - 其==**极限波特率**== = **2W**（单位：波特，即 码元/秒）
 - 其==**极限比特率**== = $2W\log_2{K}$ b/s

*W是信道的频率带宽（单位：Hz）*

### 香农定理

==**香农定理**==：对于一个==**有噪声**==、**带宽有限**的信道
 - 其==**极限比特率**== = $W\log_2{(1+S/N)}$ bps
*S/N为信噪比 = $\frac{信号的功率}{噪声的功率}$*

由于在通信领域，信号功率往往比噪声功率大得多，采用**无单位记法**，信噪比会非常大
所以以**分贝dB**为单位表示信噪比：
$$信噪比 = 10\log_{10}{(S/N)}$$
### 奈奎斯特定理&香农定理

奈奎斯特定理说明了：
 - 如果波特率太高，会导致**码间串扰**，即接收方无法识别码元
 - 带宽越大，信道传输码元的能力越强
 - ==奈奎斯特定理并未对一个码元最多可以携带多少比特做出解释==

香农定理说明了：
 - 提升信道带宽、加强信号功率、降低噪声功率，都可以提高信道的极限比特率
 - ==结合奈奎斯特定理，可知，在带宽、信噪比确定的信道上，一个码元可以携带的比特数是有上限的==

## 编码和调制

### 概念

变换器：将二进制数据转换为信号
反变换器：将信号转换为二进制数据

**编码**：二进制数据 -> 数字信号
**解码**：数字信号 -> 二进制信号

**调制**：二进制数据 -> 模拟信号
**解调**：模拟信号 -> 二进制数据

### 常用的编码方法

**不归零编码NRZ**（Non Return to Zero Code）：低0高1，中不变

**归零编码RZ**（Return to Zero Code）：低0高1，**中归零**
 - 不管是低电平还是高电平，在一个信号周期的中间使信号归零
 - **作用**：让发送方和接收方保持相同的节奏

**反向非归零编码NRZI**（Non Return to Zero Inverted Code）：跳0不跳1看起点，中不变
 - 看每个信号周期的起点位置信号有没有发生跳变

**曼彻斯特编码**：跳0反跳1看中间，中必变
 - **上跳为0下跳为1**，或者上跳为1下跳为0

**差分曼彻斯特**：跳0不跳1看起点，中必变
 - 与NRZI类似，关注每个周期的起点位置，发生跳变则为0，没有发生则为1
 - 与NRZI区别：在每个周期中间位置，==差分曼彻斯特编码必会发生跳变==
 - **好处**：让发送方和接收方保持相同的节奏，且**提升信号的抗干扰能力**

| 编码          | 自同步能力         | 浪费带宽？    | 抗干扰能力 |
| ----------- | ------------- | -------- | ----- |
| 不归零编码NRZ    | 无             | 不浪费      | 弱     |
| 归零编码RZ      | 有             | 浪费       | 弱     |
| 反向非归零编码NRZI | 若增加冗余位，可支持自同步 | 浪费一点，但不多 | 弱     |
| 曼彻斯特编码      | 有             | 浪费       | 强     |
| 差分曼彻斯特编码    | 有             | 浪费       | 强     |
**自同步能力**：信源和信宿可以根据信号完成节奏同步，无需时钟信号

**以太网默认使用曼彻斯特编码**
### 常用的调制方法

**基带信号**：来自信源的数字信号，需**调制**后才能在某些信道上传输

假设：一个信号周期为4$\pi$毫秒，记信号值为y，记时间为x

**调幅AM**（Amplitude Modulation）：正弦波**振幅**，没有振幅的表示0，有振幅的表示1
 - y = 0·sin 2x，表示二进制0
 - y = 1·sin 2x，表示二进制1
 - 幅移键控ASK

**调频FM**（Frequency Modulation）：正弦波**频率**
 - y = sin 1·x，表示二进制0
 - y = sin 2·x，表示二进制1
 - 频移键控FSK

**调相PM**（Phase Modulation）：正弦波**相位**
 - y = sin(x+0)，表示二进制0
 - y = sin(x+$\pi$)，表示二进制1
 - 相移键控PSK

让一个码元**携带更多bit**：
若设计**K个幅值**，则$1码元 = \log_2K$ bit

**正交幅度调制QAM**：将==AM、PM==结合起来，形成叠加信号
 - 若设计==m种幅值、n种相位==，则将AM、PM信号两两复合，可以调制出**mn种信号**，则QAM $1码元 = \log_2mn$ bit
 - OAM-xx，即调制**xx种信号**，1码元携带$\log_2xx$ bit数据

# 传输介质

**传输介质**（Transmisson Medium）：

## 传输介质

### 导向型传输介质

#### 双绞线

网线内部就有4组双绞线

**双绞线**（Twisted Pair）：由两根导线相互**绞合**而成
 - **有屏蔽层**：屏蔽双绞线STP
 - **无屏蔽层**：非屏蔽双绞线UTP

**抗干扰能力**：**较好**。绞合、屏蔽层可以提升抗电磁干扰能力

提高传输速率的方法：==提高绞合度、增加屏蔽层==
 - 抗电磁干扰能力强
 - 信道噪声功率低
 - 信道极限速率高

#### 同轴电缆

**同轴电缆**：由**内导体**（传输信号）+ **外导体屏蔽层**（抗电磁干扰）组成

**抗干扰能力**：好，屏蔽层带来良好的抗干扰能力
- 早期局域网、早期有线电视
- 内导体越粗，电阻越低，传输过程中信号衰减越少，传输距离越长

#### 光纤

**光纤**：主要由**纤芯***（高折射率） + **包层**（低折射率） 构成
- 利用光的**全反射**特性，在纤芯内传输光脉冲信号

**分类**：
 - **单模光纤SMF**（Single-Mode Fiber）：只有**一条光线**在一根光纤中传输，适合**长距离传输**，传输损耗小
    - 纤芯更细，直径小于一个波长
 - **多模光纤MMF**（Multi-Mode Fiber）：**多条光线**在一根光纤中传输，适合**近距离**传输，远距离传输光信号容易失真
    - 纤芯更粗

**抗干扰能力**：非常好。光信号对电磁干扰不敏感

**优点**：
 - 传输损耗小
 - 长距离传输时中继器少
 - 很细很省布线空间

### 以太网对有线传输介质的命名规则

**速度 + Base + 介质信息**
- Base，即Baseband，基带传输，传输数字信号（采用曼彻斯特编码）

**举例**
- 10Base5 --- 10Mbps，同轴电缆，最远传输500m
- 10BaseF* --- 10Mbps，光纤
- 10BaseT* --- 10Mbps，双绞线

### 无线传输介质

**无线电波**：
 - **穿透能力强**
 - **传输距离长**
 - **信号指向性弱**
*比如：手机信号、WIFI*

**微波通信**：
 - **频率带宽高**
 - **信号指向性强**
 - 保密性差（容易被窃听）
 *卫星通信（卫星通信作为信号中继器，传播时延较大）*

其本质上都是使用**电磁波** $C = \lambda F$
 - 电磁波频率、波长成反比关系
 - **频率越高，数据传输能力越强**
 - **波长越短**，信号**指向性越强**，信号越趋于直线传播
 - 波长越长，绕射性越好，也就是信号**穿墙**能力越强

**结论**：
 - **长波**更适合长距离、非直线信道
 - **短波**更适合短距离、高速通信，若用于长距离通信需建立中继站
 - **短波**信号指向性强，要求信号接收器==对准==信号源

*三颗地球同步卫星即可覆盖请求任何角落*
 - **传播时延较大**，但可用近地卫星群解决（星链）

## 物理层接口的特性

**机械特性**：指明接口所用接收器的形状和尺寸、引脚数目和排列、固定和锁定装置等

**电气特性**：指明在接口电缆的各条线上出现的电压范围、传输速率、距离限制等

**功能特性**：指明某条线上出现的某一电平的电压意义

**过程特性**（规程特性）：指明对于不同功能的各种可能事件的出现顺序

# 物理层设备

## 中继器 Repeater

信号传输时，若**传输距离太长，数字信号会失真**

比如物理层规定 -- 0.5~1.5V为低电平，4.5~5.5V为高电平，不符合此标准的信号无效。中继器收到信号后，会将低电平**整型**成1V，高电平**整型**为5V，再输出

**中继器**
 - 只有两个端口。通过一个端口接收信号，**将失真信号整形再生，并转发至另外一个端口**
 - 仅支持半双工通信（两端连接的节点**不可同时发送**数据，会导致**冲突**）
 - 中继器两个端口对应两个**网段**

## 集线器 Hub

**集线器**：
 - 本质上是**多端口**中继器。集线器将其中一个端口接收到的**信号整形在说后，转发到所有其他端口**
 - 各个端口连接的节点**不可同时发送**数据，会导致**冲突**
 - 集线器的N个端口对应N个**网段**，各网段属于同一个**冲突域**

### 冲突域

**冲突域**：如果两台主机同时发送数据会导致**冲突**，则这两台主机处于同一个冲突域（碰撞域）

处于同一冲突域的主机在发送数据前需要进行==**信道争用**==

**结论**：==集线器不能隔离冲突域==

## 集线器和中继器的特性

集线器和中继器不能**无线串联** --- 比如 10Base5的5-4-3原则
 - 5-4-3原则：使用集线器（中继器）连接10Base5网段时，最多只能串联5个网段，使用4台集线器（中继器），只有3个网段可以挂接计算机

集线器连接的网络，**物理上是星形拓扑**，**逻辑上是总线型拓扑**
 - 数据广播型传输，存在**信道争用**问题

集线器连接的各个网段**共享带宽**

**与教材冲突的特性**：
 - 集线器可以连接不同的传输介质，因此两个网段的物理层接口特性可以不同（意味着集线器连接的网段，物理层协议可以不同）
 - 集线器如果连接速率不同的网段，会导致所有网段速率**向下兼容**
