## 直接插入排序

**过程**：
 1. A\[0\]作为哨兵位
 2. 未排序序列的首个元素A\[i\]（i≥2）会**从后往前**和已有序列的元素逐个对比
     1. 若A\[i\]≥已有序列中的某个元素，不做操作（==这一步并未改变两个相等元素的前后顺序，所以是**稳定**的算法==）
     2. 若A\[i\]≤已有序列中的某个元素，待插入元素A\[i\]被复制到哨兵位，将A\[i\]之前大于哨兵的元素往后移动一个位置，继续进行比较，直至确认A\[i\]的插入位置，将哨兵位的元素复制到空位上

**实现**：
```cpp
void InsertSort(int A[],int n){
	int i,j;
	for(i=2;i<=n;i++){
		if(A[i]<A[i-1]){
			A[0]=A[i];//哨兵位存储
			for(j=i-1;A[0]<A[j];--j){//从后往前找待插入的位置
				A[j+1] = A[j];//向后挪位
			}
			A[j+1]=A[0];//复制到插入位置
		}
	}
}
```

### 情况分析

**最好情况**：
 1. 未排序序列的每个元素只需要和前面的一个元素进行比较后就可以插入已有序序列
 2. **总比较次数** = 1+1+1+...+1 = n-1
 3. **总移动次数** = 0次

**最坏情况**：
 1. 未排序序列的每个元素都需要和已有序列的每个元素进行比较后才能插入有序序列
 2. **总比较次数** = 1+2+3+4+...+n-1 = $\dfrac{n(n-1)}{2}$
 3. **总移动次数** = 3+4+...+（n+1） = $\dfrac{(4+n)(n-1)}{2}$
     - 第一个3次移动：把元素放入哨兵位+第一个元素后移+哨兵位放到第一个元素原来的位置

## 折半插入排序

*一般和直接插入放一起考*
 - 其实就是将直接插入排序**查找插入位置**的算法改为**折半查找**

**思想**：
 1. 折半插入排序可以**优化**直接插入排序的比较次数，但没有改变移动次数，所以折半插入排序的**平均时间复杂度**仍然是$O(n^2)$
 2. 折半插入排序中，每一趟的**比较次数**==最多==为$\lceil\log_2(i+1)\rceil$(i为已有序序列的元素个数)
 3. 折半插入排序只适用于**顺序表**

### 情况分析

**最佳情况**：当目标值位于数组的中间，在这种情况下，正好每次进行一次比较

**平均情况**：数量级固定为$\log_2i$次，因为每次比较时，折半查找都会将数组切成两半，但这是一个近似值，确切数字会根据初始序列的情况略有不同

**最坏情况**：当目标值不在数组中，在这种情况下，正好进行$\lceil\log_2(i+1)\rceil$的比较

## 希尔排序

**思想**：
 1. 将待排序表相隔几个元素分割成几个子表，第一轮$dk=\dfrac{n}{2}$,第一轮$dk=\dfrac{dk}{2}$，以此类推
     - 这里可能会导致==相同元素的前后位置发生变化==，所以希尔排序是**不稳定**的算法
 2. 对每个子表分别进行直接插入排序
 3. 整个表中的元素已基本有序时，**再对全体记录**进行一次直接插入排序

## 冒泡排序

**思想**：
 1. 不断让相邻的两个元素进行比较，每一趟确定一个最小值的最终位置
 2. 可以左往右，也可以右往左
 3. 当上一趟没有发生任何交换时，可以直接停止冒泡排序

```cpp
void BubbleSort(int A[],int n){
	for(int i=0;i<n-1;i++){
		bool flag = false;//表示本次冒泡是否发生交换的标志位
		for(int j=n-1;i>i;j--){
			if(A[j-1]>A[j]){
				swap(A[j-1],A[j]);
				flag=true;
			}
		}
		if(flag==false){//若没有发生交换，则说明已经有序
			return;
		}
	}
}
```

### 情况分析

**空间复杂度**：仅占用常数个辅助单元，所以空间复杂度为$O(1)$

**时间效率**：
 - **最好情况**（有序）：仅需一趟冒泡，共n-1次比较，0次移动，时间复杂度为$O(n)$
 - **最坏情况**（逆序）：需要n-1趟冒泡，第i趟进行n-i次比较，且每次比较需要3次移动完成交换元素的位置
    - 这里的3次移动：暂存位保存j，j-1移动到j，暂存位移动到j-1
$$
\begin{gather*}
总比较次数_{最坏}=\sum_{i=1}^{n-1}(n-i)=\dfrac{n(n-1)}{2}\\\\
总移动次数_{最坏}=3\times总比较次数_{最坏}=\dfrac{3n(n-1)}{2}
\end{gather*}
$$
**稳定性**：比较相邻元素时，相同元素不会发生交换，所以冒泡排序是稳定的算法
**适用性**：冒泡排序适用于顺序存储和链式存储的线性表

## <span style="color:red">快速排序</span>

*由于快排适用范围广，且各项效率均衡，考试涉及到排序的算法可以直接写快排代码混分*

**思想**（递归）：
 1. 选择一个元素作为枢轴povit元素（一般是表中第一个元素）
 2. 表的左右两侧设立**low**和<span style="color:red;font-weight:bold">high</span>，初始时**low**=1，<span style="color:red;font-weight:bold">high=L.length</span>
 3. <span style="color:red;font-weight:bold">high</span>指针往<span style="color:red;font-weight:bold">左</span>走，碰到比枢轴元素<span style="color:red;font-weight:bold">小</span>的就把元素放到**low**位置，然后操作**low**指针
    **low**指针往**右**走，碰到比枢轴元素**大**的就把元素放到<span style="color:red;font-weight:bold">high</span>位置，然后操作<span style="color:red;font-weight:bold">high</span>指针
     - 这里可能导致两个相同元素的相对位置发生改变，所以快排也是一种**不稳定**的排序算法
 4. 此时第一轮结束后，枢轴就到达了其最终位置，即其左侧元素均小于枢纽，而右侧元素均大于枢纽
 5. 而后，分别对其左右侧的子表进行递归的操作，直至子表中==没有元素或只有一个元素==停止，此时表中元素完全有序

*考研考察的划分操作，通常以子表的第一个元素作为枢轴对表进行划分*
**代码实现如下**：(假设数据均为int型)
```cpp
int Partition(int A[],int low,int high){
//划分操作，而正式的快排就是不断调用这个函数
	int pivot = A[low];//将当前表中第一个元素作为枢轴
	while(low<high){
		while(low < high&&A[high]>=pivot) --high;
		A[low] = A[high];//将比枢轴小的放到左边
		while(low < high&&A[low]<=pivot) ++low;
		A[high] = A[low];//将比枢轴大的放到右边
	}
	A[low] = pivot;//将枢轴元素放到最终位置
	return low;
}

//快速排序
void QuickSort(int A[],int low,int high){
	if(low < high){
		int pivotpos=Partition(A,low,high);
		//依次对两个子表进行递归的排序
		QuickSort(A,low,pivotpos-1);
		QuickSort(A,pivotpos+1,high);
	}
}
```

**知识点**：
 1. 当子表长度为1时，代码实际上会再次**调用一次**快排，但模拟时忽略了这一次调用
 2. 对一个子表调用一次快排**至少**确定一个元素的最终位置，pivot一定确认最终位置，且左边元素小于它，右边元素大于它
 3. 快排的**最好情况**是每次选择的pivot刚好可以把表分成**相对均匀**的左右两份，**最坏情况**是初始序列**基本有序**
 4. 快排递归树的树高和递归深度一致，最大递归深度为n，最小递归深度为$\log_2 n$
 5. 快排依赖**随机访问**的特性，因此适用于**顺序存储**

**做题技巧**：进行两趟快排，如果两个元素确认的最终位置，则其中**必有一个在数组边界**（2019真题）

### 情况分析

**空间效率**：
 - 最好情况：即每次选择的pivot恰好可将表分成相对均匀的两个部分，此时为$O(\log_2 n)$
 - 最坏情况：即每次选择的pivot为表中最大/小元素，此时为$O(n)$
 - 平均情况：$O(\log_2n)$

**时间效率**:
 - 最坏情况：每趟划分每个排序表中仅减少一个元素，总比较次数约为$\dfrac{n(n-1)}{2}$，**时间复杂度**为$O(n^2)$
 - 最佳情况：每次划分都均匀分为两部分，此时**时间复杂度**为$O(n\log_2n)$
 - ==快速排序在实际应用中平均运行时间非常接近最佳情况，所以它是所有内部排序中**平均性能最优**的排序方法==

**稳定性**：快速排序是**不稳定**的排序算法

## 简单选择排序

**思想**：
 1. 每一趟在无序序列中找到最小的元素与无序序列的第一个元素进行交换，直到整体有序
 2. 每一趟设置一个最小值指针，初始时指向无序序列的第一个元素，遍历结束后指向本趟无序序列中的最小值

**代码实现**：
```cpp
void SelectSort(int A[],int n){
	for(int i=0;i<n-1;i++){
		int min = i;//记录最小元素的位置
		for(int j=i+1;j<n;j++){
			if(A[j]<A[min]) min = j;//在无序序列中找最小元素
		}
		if(min != i) swap(A[i],A[min]);//交换函数依旧移动三次
	}
}
```
### 情况分析

**时间效率**：
 - 最坏情况：移动次数最多不超过3(n-1)次
 - 最好情况：移动次数为0次
 - 但是**比较次数**与序列无关，始终为$\frac{n(n-1)}{2}$，**时间复杂度**为$O(n^2)$

**稳定性**：**不稳定**的排序算法

## 堆排序（大根堆为例）

**思想**：
 1. 建堆
     1. 从最后一个分支节点所在的子树开始，根节点与较大孩子互换
     2. 逐个从后往前让所有子树满足大根堆的定义
     3. 如果在调整的过程中出现后面的调整影响到前面调整好的子树，应该立刻将被影响的部分恢复好，再继续往前进行调整
 2. 调整堆
     1. 交换堆顶和堆底元素
     2. 从上到下把受影响的部分重新调整为大根堆
 3. 堆的删除：**删除堆顶元素**，再用堆底元素填补空位，从上到下调整堆
 4. 堆的插入：新元素被插入到堆底，插入后需要从下往上调整堆
 5. 左右孩子的值相等时：选择**左**孩子和**父亲**交换
 6. **堆是一个完全二叉树**

**代码思想**：
```cpp
//建堆
void HeapAdjust(int A[],int k,int len){
	//对以k为根的子树的调整
	A[0] = A[k];//A[0]暂存子树根节点
	for(int i=2*k;i<=len;i*=2){//沿关键字较大的子节点向下筛
		if(i<len&&A[i]<A[i+1]){
			i++;
		}
		if(A[0]>A[i]) break;
		else{
			A[k] = A[i];
			k=i;
		}
	}
	A[k]=A[0];//被筛选节点的值放入最终位置
}
void BuildMaxHeap(int A[],int len){
	for(int i=len/2;i>0;i--){ //从最后一个分支节点到根节点
		//这里取len/2是因为对于完全二叉树数组而言，数组前一半元素为非叶节点
		HeapAdjust(A,i,len);//反复调整子树
	}
}

//堆排序
void HeapSort(int A[],int len){
	BuildMaxHeap(A,len);//建堆
	for(int i=len;i>1;i--){
		Swap(A[i],A[1]);//不断的把堆顶元素放到数组末尾
		HeapAdjust(A,1,i-1);//并对剩余元素进行调整
	}
}
```

### 情况分析

**空间效率**：仅使用了常数个辅助单元，**空间复杂度**为$O(1)$

**时间效率**：建堆的时间复杂度为$O(n)$，随后进行n-1次堆顶输出与调整，每次**调整的时间复杂度**为$O(\log_2n)$，因此堆排序在最好、最坏、平均的**时间复杂度**均为$O(n\log_2n)$

**稳定性**：堆排序为**不稳定**的排序算法

**适用性**：堆排序完全依赖完全二叉树**随机访问**的特性，仅适用于**顺序存储的线性表**

## 归并排序（二路归并为例）

**思想**：
 1. 假设初始序列含有n个记录，则可将其看成n个有序的子序列，每个子序列的长度为1，然后两两归并，得到$\lceil\dfrac{n}{2}\rceil$个长度为2或1的有序子序列，对这些子序列再两两归并，如此往复，一直到得到一个长度为n的子序列为止
 2. **N**个元素进行**K**路归并，趟数$\lceil\log_KN\rceil$
 3. 长度为m和n的有序表进行二路归并，最多比较**m+n-1**次，最少比较**min{m,n}**次
     - **最少比较**：两个段进行归并时，比较次数取决于关键字更小的段中的元素个数
	     - 例如：{1，2}{4，5，6}和{1,2,3}{4,5}，比较次数显然前者更少
	 - **最多比较**：两个段相当于是插空的，例如{1,3,5}{2,4,6}
 4. 二路归并排序的递归代码依赖于**分治策略的算法思想**
 

归并排序的代码依赖于一个marge()函数，其功能是将前后相邻的有序子表合并为一个有序表
```cpp
void Merge(int A[],int low,int mid,int high){
	//表A的两段A[low...mid]和A[mid+1...high]各自有序，将其合并
	int i,j,k;
	vector<int> B = A;//将A中的元素复制进B
	for(i=low,j=mid+1,k=low;k<=mid&&j<=high;k++){
		if(B[i]<=B[j])//比较B两个段中的元素
			A[k]=B[i++];//将值较小的元素放入B
		else
			A[k]=B[j++];
	}
	//下述while最多只会有1个运行
	while(i<=mid) A[k++]=B[i++];
	while(j<=high) A[k++]=B[j++];
}

//二路归并排序
void MargeSort(int A[],int low,int high){
	if(low<high){
		int mid = (low+high)/2;
		MergeSort(A,low,mid);//对左侧进行递归排序
		MergeSort(A,mid+1,high);//对右侧进行递归排序
		Merge(A,low,mid,high);//归并
	}
}
```

### 情况分析

**空间效率**：归并排序需要维持一个与待排表等长的辅助数组，因此**空间复杂度**为$O(n)$

**时间效率**：每趟归并需要遍历所有n个元素，**时间复杂度**为$O(n)$，共需进行$\lceil\log_2N\rceil$趟，所有总**时间复杂度**为$O(n\log_2n)$

**稳定性**：当两个元素相等时优先取前一个，所以归并排序是**稳定的**排序算法

**适用性**：归并排序仅需顺序访问元素，因此适用于顺序存储和链式存储的线性表

## 基数排序

**思想**：
 1. **不比较**关键字的大小，而是根据关键字中各位的值，对排序记录进行若干趟分配和收集来实现排序
 2. 默认使用**LSD低位优先法**
     - 相当于使用九个队列对关键字的各个位分别进行入队出队，最终得到有序序列

### 情况分析

**空间效率**：一趟排序需要的辅助空间为r(r个队列)，所以时间复杂度为$O(r)$

**时间效率**：共进行d趟的分配和收集，每趟分配需遍历n个元素，所需时间为$O(n)$，每次处理r个队列，所需时间为$O(r)$，所以总的**时间复杂度**为$O(d(n+r))$

**稳定性**：由于每次都是按原序列进行入队，所以基数排序是**稳定的**排序算法

**适用性**：基数排序适用于顺序存储和链式存储的线性表，**链式结构**尤其适合
