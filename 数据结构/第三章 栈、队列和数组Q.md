## 队列的假溢出问题

集中体现在front指针前面的空间无法利用的问题
 - 解决：让rear指针指回第一个节点

## 循环队列的指针设置

| 状态  | 代码                                                     |
| --- | ------------------------------------------------------ |
| 队空  | `rear == front(=0)`                                    |
| 队满  | `rear == front(=0)`                                    |
| 入队  | `Q.data[rear] = x`<br>`rear = (rear + 1)% MAXSIZE`     |
| 出队  | `x = Q.data[front]`<br>`front = (front + 1) % MAXSIZE` |
bug：队空/队满无法判断

## 区别队空队满的三个方案

| 方案  | 内容                         |
| --- | -------------------------- |
| 方案1 | 牺牲一个单元不放元素                 |
| 方案2 | 设置tag，删除成功后置tag为0，插入成功后置为1 |
| 方案3 | 设置num表示队列中元素的个数            |

## 循环队列的长度问题

循环队列的长度 = `(MAXSIZE + rear - front + 1) % MAXSIZE`

## 括号匹配

**解决的问题**
 1. 左括号必须使用相同类型的右括号闭合
 2. 左括号必须以正确的顺序闭合
 3. 每个右括号都有一个对应的相同类型的左括号

*即每当出现一种左括号，计算机便等待对应的右括号，但在此期间若出现另外一种左括号，则将其视为更高优先级，转而等待新类型的右括号，若遇到当前等待的右括号，则成对消除*

## 中缀表达式转后缀表达式

**最常考**：

| 扫描顺序  | 从左到右扫描                                                           |
| ----- | ---------------------------------------------------------------- |
| 遇到操作数 | 直接输出，不做栈操作                                                       |

## 稀疏矩阵的存储

**存储方式**：
 1. 三元组
     - 除了三元组表之外，还需保存稀疏矩阵的行数、列数和非零元素的个数
 2. 十字链表

## 特殊矩阵的存储

**对称矩阵**：`A[i][j]=A[j][i]`
 - 存储时按行/列优先只存储上三角或下三角（包含对角线）

**三角矩阵**：除三角区域外的元素均为常数c或0
 - 存储三角区域元素及一个常数c($c\neq0$)

**对角矩阵**：所有的非零元素集中在以对角线为中心的带状区域中，除了第一行和最后一行有两个元素，其余行全部都是三个元素

问：元素$A[i][j]$在一维数组的下标是？
 - 下标从0开始：A==**前有几个元素**==，下标对应是几
 - 下标从1开始：A==**是第几个元素**==，下标对应就是几
