# 考点1 图的概念和性质

##### 8.26

选择题考频：4/16年
大题考频：0/16年

**知识点**：
 1. 假设有两个图$G=(V,E)\,,G'=(V',E')$，如果$V'\subseteq V\,,E'\subseteq E$，则称
     - 一定确保V'和E'可以扯上关系
 2. 无向完全图有$\dfrac{n(n-1)}{2}$条边，有向完全图有$n(n-1)$条弧
     - 完全图一定是**连通/强连通**的，并且完全图的边数是==给定顶点数量==时**最多的**
 3. 连通分量 = 无向图中的极大连通子图，强连通分量 = 有向图中的极大强连通子图
     - 极大表示==边数达到顶点能承受的最大数量==，即原图中和某顶点相关的边都需要出现
 4. 生成树 = 无向连通图中一个包含图中**所有顶点**的**极小连通子图**
     1. 极小表示保证连通的前提下边数要达到最小
     2. 极小连通子图本身不要求必须包含图中的所有顶点
     3. 最小生成树MST是所有生成树中**边的权值之和最小的生成树**
 5. 对于无向图而言，最少需要 n-1 条边才能连通，边数大于 n-1 时**必有环**；
    对于有向图而言，最少需要n条弧才能保证强连通（==得形成一个环==）
 6. 无向图中所有顶点的**度之和**等于**边数的二倍**，
    有向图所有顶点的入度之和 = 出度之和 = 弧数
 7. n个顶点的无向图最少有1个连通分量，最多有n个连通分量
     - 最少情况下n个顶点两两之间都有路径，所以无向图本身就是自己唯一的连通分量
     - 最多情况下，每个顶点独立并自成一个连通分量
 8. 【保证连通】和【可以实现连通】的区别：
     1. 保证连通是指 无论边怎么换位置，图都是连通的
     2. 可以实现连通是指 边在某些位置中可以构造出连通图，但如果换位置可能就无法确保依旧连通
    - 比如：
        1. 让n个顶点的无向图实现连通至少需要几条边？
            - $n-1$
        2. 让n个顶点的无向图保证连通至少需要几条边？
            - $\dfrac{(n-1)(n-2)}{2}+1$

# 考点2 邻接矩阵和邻接表

选择题考频：1/16年
大题考频：3/16年

**邻接矩阵**：
 1. 无向图：顶点Vi的度 = 第i行元素之和 = 第i列元素之和
 2. 有向图：
     1. 顶点Vi的出度 = 第i行元素之和
     2. 顶点Vi的入度 = 第i列元素之和

**邻接表**：
 1. 无向图：顶点Vi的度 = 第i个边表中的结点个数
 2. 有向图：
     1. 顶点Vi的出度 = 第i个边表中的结点个数
     2. 顶点Vi的入度需要遍历整个顶点的边表才能得出，即顶点Vi的入度就是在边表中出现的次数

**相关结论**：
 - **邻接矩阵**：==$A^k[i][j]$表示从顶点i到顶点j之间长度为k的路径条数==
    - 无向图：邻接矩阵是对称的，可以压缩存储为上（下）三角矩阵，即需要$\dfrac{n(n-1)}{2}$个单元来存储边
    - 有向图：n个顶点的图需要$n^2$个单元来存储边
 - **邻接表**：
    - 无向图：n个顶点表结点 + 2e个边表结点（边表结点一定是偶数个）
    - 有向图：n给顶点表结点 + e个边表结点

## 结点结构

### 十字链表（存有向图）

**顶点结点**：

| 结点编号 | data | FirstIn          | FirstOut         |
| ---- | ---- | ---------------- | ---------------- |
| 描述   | 存放数据 | 指向以data为弧头的第一个顶点 | 指向以data为弧尾的第一个顶点 |

**弧结点**：

| tailVex   | headVex   | hLink     | tLink     | （info）    |
| --------- | --------- | --------- | --------- | --------- |
| 弧尾指向顶点的编号 | 弧头指向顶点的编号 | 弧头相同的下一条弧 | 弧尾相同的下一条弧 | 弧的信息，一般省略 |

### 邻接多重表（存无向图）

**顶点结点**：

| 结点编号 | data   | FirstEdge     |
| ---- | ------ | ------------- |
| 描述   | 用于存放数据 | 指向第一条依附于该顶点的边 |

**弧结点**：

| iVex        | iLink          | jVex         | jLink          | （info）    |
| ----------- | -------------- | ------------ | -------------- | --------- |
| 该边依附的两顶点编号1 | 指向下一条依附于iVex的边 | 该边依附的两顶点的编号2 | 指向下一条依附于jVex的边 | 边的信息，一般省略 |

## 优点

**十字链表**：结合了邻接表和逆邻接表，可以方便的计算顶点vi的**入度和出度**，寻找依附于某一结点的所有弧

**邻接多重表**：每条边只会被存储一次，且所有依附于同一结点的边都背串联在一个链表中，便于**计算结点的度**，寻找依附于某一结点的边

## DFS思想在不同存储结构的实现

```cpp
bool visited[MVNun];
void DFSTraverse(Graph G){
//调用DFS的次数 = 连通分量的个数
	for(v = 0; v < G.vexnum; ++v){
		visited[v] = false;
	}
	for(v = 0; v < G.vexnum; ++v){
		if(!visited[v]) DFS(G,v);
	}
}

void DFS(Graph G,int v){
	cout << v;
	visited[v] = true;
	for(w = FirstAdjVex(G,v); w >= 0; w = NextAdjVex(G,v,w)){
		if(!visited[w])
			DFS(G,w);
	}
}
```

即：从一个顶点开始，先标记访问并输出它，再去检查它的邻接点
 - 若邻接点**未访问**，就对邻接点再次调用DFS
 - 重复上述操作，直到所有节点被访问

**DFS核心代码**：
```cpp
	for(w = FirstAdjVex(G,v); w >= 0; w = NextAdjVex(G,v,w)){
		if(!visited[w])
			DFS(G,w);
	}//其对应的生成树树高较高
```

**过程**（对于**邻接矩阵**而言）：
 - 从给定的参数顶点v开始，首先遍历邻接矩阵中第v行的所有元素
 - 如果第w列的值不为0，说明顶点v与顶点w之间存在边
    - 若此时顶点w未被访问，则将w作为参数递归调用DFS
 - 继续以同样的方式访问w的所有邻接点，直到所有可达节点被访问为止

**时间复杂度**：$O(n^2)$

**过程**（对于**邻接表**而言）：
 - 从给定的参数顶点v开始，首先访问v所对应的邻接表，获取==第一个邻接点指针p==
 - 然后沿着邻接表的边表不断向后遍历，每次取出当前边所指向的邻接点w
    - 若此时w未被访问，就将w作为参数递归调用DFS
 - 继续以同样的方式访问w的所有邻接点，直到所有可达节点被访问为止

**时间复杂度**：$O(n+e)$

## BFS思想在不同存储结构的实现

**BFS广度优先搜索**（Breadth-First-Search）

**实现代码**：
```cpp
bool visited[MVNum];
void BFSTraverse(Graph G){
	// 其中调用BFS()的次数 = 连通分量的个数
	for(v = 0;v < G.vexnum; ++v){
		visited[v] = false;
	}
	for(v = 0;v < G.vexnum; ++v){
		if(!visited[v]) BFS(G,v);
	}
}

void BFS(Graph G,int v){
	cout << v;
	visited[v] = true;
	InitQueue(Q);//BFS中使用了队列
	EnQueue(Q,v);
	while(!QueueEmpty(Q)){
		DeQueue(Q,u);
		for(w = FirstAdjVex(G,u);w >= 0; w = NextAdjVex(G,u,w)){
			if(!visited[w]){
				cout << w;
				visited[w] = true;
				EnQueue(Q,w);
			}
		}
	}
}
```

**思想**：
 - 从一个顶点开始，先标记访问并输出它，再将其加入队列
 - 然后不断从队列中取出队头顶点检查该顶点的所有邻接点
    - 如果某个邻接点从未被访问，就标记访问、输出，并加入队列
 - 重复上述过程，直到队列为空为止

**过程**：（对应**邻接矩阵**而言）
 - 从给定的参数顶点v开始，首先输出顶点v，并将其标记为访问，将达到v入队
 - 当队列不空时循环执行以下操作：
    1. 从队列中取出队头顶点 u，遍历邻接矩阵第u行的所有元素，依次检查每个顶点w
    2. 如果G.arcs\[u]\[w]不为0，说明u与w之间存在边
    3. 如果顶点w尚未被访问，则输出w、标记访问，并将w入队
 - 继续检查u行中剩下的所有列，直到扫描完整行

**时间复杂度**：$O(n^2)$

**过程**（对于**邻接表**而言）：
 - 从给定的参数顶点v开始，首先输出顶点v，并将其标记为已访问，将达到v入队
 - 当队列不空时循环执行以下操作
    1. 从队列中取出队头元素u，访问顶点u所对应的邻接表，获取==第一个邻接点指针p==
    2. 然后沿着邻接表的边表不断向后遍历，每次取出当前边所指向的邻接点w
    3. 若此时w未被访问，则输出w并标记访问，并将w入队
    4. 继续遍历邻接表的下一项，直到p为NULL为止

**时间复杂度**：$O(n+e)$

对于遍历**同一张图**而言：DFS的树高 ≥ BFS的树高

## 图与树的遍历关联

图的DFS类似于树的先序遍历

图的BFS类似于树的层序遍历

### 判断环路

**DFS判断有向图环路过程**：
 1. 从某个顶点触发进行DFS
 2. 在遍历过程中，如果遇到某个邻接点处于正在访问的状态，说明存在环路
 3. 为了准确判断，通常需要为每个顶点维护三种状态：==未访问、正在访问、已访问==

**代码实现**：
```cpp
void CheckGraphCycle(Graph G){
	for(v=0;v<G.vexnum;v++){
		if(status[v] == Unvisited)
			DetectCycleDFS(G,v);
	}
	if(hasCycle)
		cout << "存在回路"
	else
		cout << "无回路"
}

bool hasCycle = false;
void DetectCycleDFS(Graph G,int v){
	status[v] = Visiting; //正在访问
	for(w=FirstAdjVex(G,v); w>=0; w=NextAdjVex(G,v,w)){
		if(status[w]==Visiting) // 再次遇到正在访问的点 -> 发现环路
			hasCycle = true;
		if(status[w]==Unvisited)
			DetectCycleDFS(G,w);
	}
	status[v] = Visited;// 已访问
}
```


**DFS判断无向图环路过程**：
 1. 从某个顶点触发进行DFS
 2. 在遍历过程中，如果遇到某个邻接点处于正在访问的状态，并且这个正在访问的节点不是上一步访问的节点，说明该无向图存在环路
 3. 为了准确判断，通常需要为每个顶点维护三种状态：==未访问、正在访问、已访问==

```cpp
void CheckGraphCycle(Graph G){
	for(v=0;v<G.vexnum;v++){
		if(status[v] == Unvisited)
			DetectCycleDFS(G,v,-1);//初始节点没有父节点
	}
	if(hasCycle)
		cout << "存在回路"
	else
		cout << "无回路"
}

bool hasCycle = false;
void DetectCycleDFS(Graph G,int v,int parent){
	status[v] = Visiting; //正在访问
	for(w = FirstAdjVex(G,v); w >= 0; w = NextAdjVex(G,v,w)){
		if(status[w]==Visiting && w != parent) 
		// 再次遇到正在访问的点 -> 发现环路
			hasCycle = true;
		if(status[w]==Unvisited)
			DetectCycleDFS(G,w,v);
			//传递当前节点作为w的父节点
	}
	status[v] = Visited;// 已访问
}
```

### 拓扑排序

**DFS实现拓扑排序的过程**：
 1. 每个顶点v在DFS退出递归之前都会记录当前的时间戳，并赋值给finishTime\[v]
 2. 因为后继节点的DFS会先于v完成，因此它们的finishTime一定比v大
 3. 最后按照finishTime从大到小排序所有顶点，就得到了一个合法的拓扑排序

**代码实现**：
```cpp
bool visited[MVNum];
int finishTime[MVNum];
int time;
void TopoSortDFS(Graph G,int v){
	visited[v] = true;
	for(w = FirstNeighbor(G,v);w >= 0; w = NextNeighbor(G,v,w)){
		if(!visited[w])
			TopoSortDFS(G,w);
	}
	time = time + 1;
	finishTime[v] = time;
}
```
*注：前提是有向无环图*

### 用BFS计算单源最短路径

**过程**：
 1. 从起点出发，将其距离初始化为0，其余所有顶点初始化为∞，并将 入队作为搜索起点
 2. 每次从队列中取出顶点u，访问它的所有未访问邻接点w，并将d\[w]设为d\[u]+1
 3. 因为BFS一层层推进的，第一个访问到的路径一定最短，最终d\[]数组记录的即为起点到每个顶点的最短路径长度

**代码实现**：
```cpp
void BFS_DISTANCE(Graph G,int u){
	for(i = 0;i < G.vexnum; i++)
		d[i] = ∞;
	visited[u] = True;
	d[u] = 0;
	EnQueue(Q,u);
	while(!isEmpty(Q)){
		DeQueue(Q,u);
		for(w = FirstNeighbor(G,u);w >= 0; w = NextNeighbor(G,u,w)){
			if(!visited[w]){
				visited[w] = True;
				d[w] = d[u] + 1;
				EnQueue(Q,w);
			}
		}
	}
}
```

# 考点5 拓扑排序

选择题考频：8/16年
大题考频：1/16年

**有向无环图**DAG图：
 1. 不能出现重复的操作数顶点
 2. 尽可能化简
 3. 整个图的运算方向需要一致

**有向无环图描述表达式**步骤：
 1. 将各个操作数不重复的排成一排
 2. 标出各个运算符的生效顺序（先后顺序有出入无所谓）
 3. 按顺序加入运算符，注意**分层**
 4. 从底向上逐层检查**同层**的运算符是否可以合体
*注：最终结果不唯一*

**拓扑排序**：对有向无环图的顶点的一种排序，它使得若存在一条从顶点A到顶点B的路径，则在排序中B出现在A的后面

**过程**：
	1. 在有向图中选择一个入度为0的顶点并输出
	2. 从图中删除该顶点和它的出度
 - 重复上述步骤，直到不存在入度为0的顶点
 - 若最终输出的顶点数小于有向图中的顶点数，则图中**存在环**（DFS和并查集同样可以查环）
 - 否则输出的顶点序列即为该图的一个拓扑排序

**拓扑排序规律总结**：
 1. 拓扑排序可能不唯一
 2. 若有向图中有环，则该图不存在拓扑排序
 3. 若有向图的拓扑“有序”序列**唯一**，则图中入度为0和出度为0的顶点都只有1个
 4. 顶点数**大于1**的强连通图不能进行拓扑排序
     - 强连通图有环
 5. 如果拓扑序列中A在B之前，原图中不一定有边<A,B>
 6. 有向无环图的拓扑序列唯一，但并不能**唯一确定**该图

```cpp
		Pop(S,i);//出栈
		print[count++] = i;//输出顶点i
		for(p = G.vertices[i].firstArc; p ;p = p->nextArc){
			//将所有i指向的顶点的入度减一，并将入度减为0的顶点压入栈s
			v = p->adjvex;
			if(!(--indegree[v])
				push(S,v);//入度为0，入栈
		}
	}
	if(count < G.vexnum)//有回路
		return false;
	else
		return true;//排序成功
}//总的时间复杂度为O(n+e)
```

# 考点6 最小生成树

选择题考频：4/16年
大题考频：2/16年

| 生成树                         | 最小生成树MST           |
| --------------------------- | ------------------ |
| 无向连通图中一个包含图中**所有节点**的极小连通子图 | 所有生成树中边的权值之和最小的生成树 |

**最小生成树相关概念**：
 1. 只有无向连通图才有生成树的概念
 2. n给顶点的图，最小生成树有 **n-1** 条边
 3. 对于最小生成树，再加一条边就会形成环路，再减一条边就会不连通
 4. 若原图存在权值相同的边，那么该图的最小生成树**可能**不唯一
 5. 若原图的边权值互不相等，那么该图的最小生成树**一定**唯一

**主要算法**：普利姆Prim算法和克鲁斯卡尔Kruskal算法

|       | Prim                                                                                                             | Kruskal                                                                                                                                       |
| ----- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
|       | 选点                                                                                                               | 选边                                                                                                                                            |
| 适用场景  | 适用于边稠密，顶点少的图                                                                                                     | 适用于边稀疏，顶点多的图                                                                                                                                  |
| 过程    | 1.初始时任选一个顶点加入树T<br><br>2.选择一个与当前T中顶点集合**距离最近**的顶点，并将其顶点和相应边加入T，每次操作后T的==顶点数和边数都加1==<br> <br>3.直到所有顶点加入T，此时有n-1条边 | 1.初始时为只有n个顶点而无边的非连通图T，每个顶点自成一个连通分量<br><br>2.按照边权值从小到大的顺序，选择当前未被选取且权值最小的边，若该边依附的顶点落在T中不同的连通分量上，则将此边加入T，否则则舍弃选择下一条<br> <br>3.直到T中所有顶点落在同一个连通分量上 |
| 时间复杂度 | $O(\|V\|^2)$                                                                                                     | $O(\|E\|\log_2\|E\|)$                                                                                                                         |

## 迪杰斯特拉Dijkstra算法

同BFS一样也是求解**单源最短路径**

**节点信息**：

| final[]         | dist[] | path[] |
| --------------- | ------ | ------ |
| 标注各顶点是否已经找到最短路径 | 最短路径长度 | 路径上的前驱 |

**算法过程**：
 1. 初始化三个数组信息
 2. 观察`final[]`数组，若`final[i]=0`且`dist[i]`最小，则将`final[i]`改为1，收录该顶点vi到最优路径集合中
 3. 对vi的邻接点vj做如下判断：
     - 如果`dist[i]+<vi,vj>`的权值 < `dist[j]`，则更新`dist[j]`与`path[j]`
 4. 循环2、3，直到所有顶点都直到最短路径

Dijsktra用于求解**单源最短路径**，不适用于**带负权值**的图

**时间复杂度**：$O(|V|^2)$

## 弗洛伊德Floyd算法

*目前还未考过*

**算法过程**：
1. 初始化矩阵
2. 依次选择顶点作为中转点
3. 以中转点为中心，画出**横、竖、对角线**三条彩带，彩带上的数字不变，逐个检查彩带外的每个数字，若该数字所在行、列对应的彩带上的值相加 **小于** 数字本身，则使用更小的值替换，否则保持不变
4. 循环**2、3**步骤，直到找到所有顶点对之间的最短路径

Floyd用于求解各顶点之间的最短路径，不适用于**带负权值回路**的图

**时间复杂度**：$O(|V|^3)$

## Dijkstra与Prim

Dijkstra与Prim算法均基于贪心法的思想，但**Dijkstra与Prim的区别**：
 1. 目的：
     - Dijkstra的目的在于**构建单源点的最短路径树**
     - Prim的目的在于**构建最小生成树**
 2. 算法思路
     - Dijkstra：每次找出到源点距离最近且没有归入集合的点，将其归入集合，并以该点为基础，继续更新
     - Prim：从一个点开始，每次选择权值最小的边，将其连接到最小生成树上，直至所有顶点连入
 3. 适用的图不同：
     - Dijkstra：**带权有向图**或**带权无向图**
     - Prim：**带权无向图**

# 考点8 关键路径

选择题考频：4/16年
大题考频：1/16年

用边表示活动的网络：**AOE**网
 - 只有当某顶点所代表的事件发生后，从该顶点出发的各有向边所代表的活动才能开始
 - 只有当进入某顶点的各有向边所代表的活动都已经完成时，该顶点所代表的事件才能发生
用顶点表示活动的网络：**AOV**网

| 时间                  | 求解方法                                                                            |
| ------------------- | ------------------------------------------------------------------------------- |
| 事件$V_i$的最早发生时间$V_e$ | $V_e(源点)=0$<br>$V_e(k)=max\{V_e(j)+Weight(V_j,V_k)\}$<br>$V_k$为$V_j$的任意后继       |
| 事件$V_i$的最迟发生时间$V_l$ | $V_l(汇点)=V_e(汇点)$<br>$V_l(k)=min\{V_l(j)-Weight(V_k,V_j)\}$<br>$V_k$为$V_j$的任意前驱 |
| 活动$a_i$的最早开始时间e     | 该弧起点顶点的$V_e$                                                                    |
| 活动$a_i$的最迟开始时间l     | 该弧终点的顶点的$V_l$减去弧的权值                                                             |

**考点**：
 - 活动的时间余量 = $l - e$
 - 关键活动的时间余量为0（$l=e$），关键活动组成了关键路径
 - 关键路径可能不唯一
 - 关键路径是持续时间最长（权值之和最大）的那条路径
 - 缩短关键路径，并不一定导致整个工期加快
    1. 如果只有一条关键路径，**缩短关键路径，一定导致整个工期加快**
    2. 如果有多条关键路径，**缩短关键路径，不一定导致整个工期加快**，因为缩短了路径长度的那条关键路径将不再是关键路径
    3. 缩短**所有关键路径上共有**的任意一个关键活动的持续时间**才会导致整个工期加快**
    4. 延长**任意一条关键路径**上的关键活动的持续时间都会导致整个工期减慢
 - 求关键路径是以**拓扑排序**为基础
