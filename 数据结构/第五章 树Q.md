# 考点1 树形推断

##### 8.12

选择题考频：7/16年
大题考频：1/16年

**知识点**：
 1. N=$n_0+n_1+...+n_n=0*n_0+1*n_1+...+n*n_n+1$
     - 即**结点总数=分支数+1**
 2. <span style="color:red">非空二叉树满足：</span>$n_0=n_2+1$
 3. 度为m的树第i层上最多$m^{i-1}$个节点
     - 树中一个结点的**孩子个数**称为该节点的度
     - 树中所有结点度的最大值称为树的度
 4. 高度为==h==的满==m叉树==一共有$\dfrac{m^h-1}{m-1}$个节点
 5. 具有n个结点的完全二叉树的高度为$\lceil\log_2{(n+1)}\rceil或\lfloor\log_2n\rfloor+1$
 6. 对完全二叉树按照层序进行编号，i=1，2，...，n则：
     1. i为**偶数**时，父结点为$\dfrac{i}{2}$，i是父节点的左孩子；i为**奇数**时，父结点为$\dfrac{i-1}{2}$，i是父节点的右孩子
     2. i的**左孩子**为==2i==或不存在，i的**右孩子**为==2i+1==或不存在
     3. i$\leq\lfloor\dfrac{n}{2}\rfloor$时，i为分支节点；$i>\lfloor\dfrac{n}{2}\rfloor$时，i为叶子节点
     4. 若n为奇数，则每个分支节点都有左右孩子；若n为偶数，则$i=\dfrac{n}{2}$（最后一个分支节点）只有左孩子
 7. 完全二叉树中**度为1**的节点$n_1$只可能有1个或0个
 8. 树越高越细（每层节点少），越矮越胖（每层节点多）
 9. 完全二叉树只有**最后两层**可能出现叶子结点
 10. 二叉树的常见公式
     1. 非空二叉树的**叶节点**数=**度为2**的结点数+**1**
     2. 设度为0，1，2的结点数为$n_0,n_1,n_2$，则结点总数为$n=n_0+n_1+n_2$
     3. 设B为总分支数，则==n=B+1==，这些分支为度为1或2的结点射出的，所以$B=n_1+2n_2$
     4. 综上：$n_0+n_1+n_2=n_1+2n_2+1\,\,\Rightarrow\,\,n_0=n_2+1$

## 二叉树的存储

**顺序存储**：一般情况从顺序表下标为1的地方开始存储

**链式存储**：n个节点的二叉链表有n+1个空链域

## 树的存储

**双亲表示法**：数组下标对应节点，存储内容对应父节点的数组下标
 - **优点**：找父节点方便
 - **缺点**：找孩子节点困难

**孩子兄弟表示法**：左孩子右兄弟，使用二叉链表存储
 - **缺点**：找父节点不方便

**孩子表示法**：用一个数组存储所有节点，每个节点用一个单链表引出其所有的孩子
 -  **缺点**：找父节点不方便

## 二叉树的四种遍历

**以先序遍历为例**
先序遍历的递归代码如下：
```cpp
void PreOrderTraverse(BiTree T){
	if(T){
		cout << T->data;
		PreOrderTraverse(BiTree T->lchild);
		PreOrderTraverse(BiTree T->rchild);
	}
}
```
整个遍历过程每个节点都会经过3次
 - ==第一次经过时：访问并输出它，然后开始遍历左子树==
 - 第二次经过时：它的左子树遍历完毕
 - 第三次经过时：它的右子树遍历完毕

中序和后序遍历类似，只是在递归代码中调整`if(T){...}`内的三句代码的顺序，本质：
 - 中序遍历：就是在**第二次**访问节点时输出它
 - 后序遍历：就是在**第三次**访问节点时输出它

而**层序遍历**有些不同（使用队列）：
```cpp
void LevelOrder(BiTree T){
	InitQueue(Q);//初始化一个队列Q
	BiTree p;
	EnQueue(Q,T);//将树的第一个节点（根节点）入队
	while(!isEmpty(Q)){//层序遍历
		DeQueue(Q,p);
		cout<< p->data;//队列的第一个节点出队，并输出它
		if(p->lchild != nullptr)
			EnQueue(Q,p->lchild);
		if(p->rchild != nullptr)
			EnQueue(Q,p->rchild);
	}//不断的将第一个节点出队，并将其左右孩子入队
}
```
层序遍历利用了**BFS**(图的广度优先搜索)的思想
 - ==当队列不空时就出队队头元素并输出==
 - 然后将队头元素所有的邻接点（这里是左右孩子）入队
 - 不断重复直到队列为空

## 非递归遍历

上述遍历代码都是通过递归实现的，以下是非递归代码（主要使用栈的思想），**先序遍历**为例：
```c++
void PreOrderTraverse(BiTree T){
	InitStack(S);//初始化一个栈
	BiTree p=T;
	BiTree q;
	while(p || !StackEmpty(S)){//先序序列是靠着输出语句得到，而并不是出入栈
		if(p){
			cout << p->data;//先序遍历先输出根节点
			Push(s,p);//将p节点压入栈中
			p = p->lchild;//p指向其左孩子
		}
		else{//左孩子不存在
			Pop(S,q);//弹出栈顶元素
			p = q->rchild;//为了让p可以回到之前指针的右子树去
		}
	}
}
```
上述代码中：入栈的顺序就是先序序列，而出栈顺序就是中序序列

而对于**中序遍历**，只需将输出语句放到如下位置：
```cpp
		else{//左孩子不存在
			Pop(S,q);//弹出栈顶元素
			cout << q->data;
			p = q->rchild;//为了让p可以回到之前指针的右子树去
		}
```

**后序遍历**最为特殊，因为无法确定节点的左右子树是否全部访问完成，，所以需要借助一个**辅助指针**
```c++
void PreOrderTraverse(BiTree T){
	InitStack(S);//初始化一个栈
	BiTree p=T,r = nullptr;
	BiTree q;
	while(p || !StackEmpty(S)){//先序序列是靠着输出语句得到，而并不是出入栈
		if(p){
			cout << p->data;//先序遍历先输出根节点
			Push(S,p);//将p节点压入栈中
			p = p->lchild;//p指向其左孩子
		}
//-------上述为前中后的通用代码---------
		else{//左孩子不存在
			GetTop(S,q);
			if(q->rchild && q->rchild != r)
			//若q右孩子非空且不是上一个访问输出的节点
				p = q->rchild;
//----------注1------------
			else{//q的右孩子为空或者q的右孩子刚被访问
				Pop(S,q);
				cout << q->data;
				r = q;
				p = nullptr;
			}
//----------注2-------------
		}
	}
}
```
**注1**：r手动记录“右子树是否访问过”
 - 取栈顶元素q
 - 若q**右孩子非空**且**不是上一个访问输出的节点**
 - 就说明q的右子树还未遍历
 - 此时不能输出q，而是先遍历q的右子树

**注2**：如果q的**右孩子为空**或者**q的右孩子刚被访问**
 - 说明此时可以正常访问输出q
 - 并使用r手动记录刚访问的节点q

## 线索化

线索二叉树是一个**物理结构**

线索二叉树节点结构如下：

| `lchild` | `lTag` | `data` | `rTag` | `rcdhild` |
| -------- | ------ | ------ | ------ | --------- |
**思想**：对于普通二叉树的某些节点，其并没有左/右孩子，所以让其左右孩子指针指向其前驱/后继节点，==Tag指针表示对应的child指针是否指向孩子节点==

树的线索化：就是在遍历的过程中去让其空孩子指针指向其前驱/后继结点的（所以线索化会根据使用前中后遍历的不同而不同），代码如下：
```cpp
pre = nullptr;//线索化的过程一直保证pre是p的前驱
if(!p->lchild){
	p->lchild = pre;
	p->ltag = 1;
}
if(pre && !pre->rchild){
	pre->rchild = p;
	pre->rtag = 1;
}
pre = p;
```

对于**中序线索树**而言：（常用结论）
 - 若某节点有**右**孩子，则它的后继节点为**右**子树最**左**下的节点
 - 若某节点有**左**孩子，则它的前驱节点为**左**子树最**右**下的节点

# 考点5 树、森林、二叉树

选择题考频：6/16年

## 树、森林和二叉树的相互转换

树$\leftrightarrow$二叉树：==左孩子右兄弟==实现互相转化

二叉树 $\Rightarrow$ 森林
 - 二叉树的根，根的右孩子，根右孩子的右孩子...均为森林中树的根节点
 - 其余按照左孩子右兄弟转换
森林 $\Rightarrow$ 二叉树
 - 森林中所有树的根节点组成二叉树的根，根的右孩子，根右孩子的右孩子
 - 其余按照左孩子右兄弟转换

**相关结论**：
- 二叉树从根节点开始，一直沿着右孩子指针向下所经过的节点个数 = 对应森林中树的数量
- 森林中树的数量 = 对应二叉树中从根节点开始，一直沿右孩子指针向下所经过的结点个数
- 二叉树的根节点**没有右子树** = 转换后是一棵树
- 二叉树的根节点**有右子树** = 转换后是一个至少有两棵树的森林
- 树的**根结点**以及**每个非终端节点的最后一个孩子** = 二叉树中没有右孩子的结点

## 树、森林和二叉树的遍历关系

遍历关系如下表：

| 树    | 二叉树  | 森林      |
| ---- | ---- | ------- |
| 先根遍历 | 先序遍历 | 先序遍历    |
| 后根遍历 | 中序遍历 | 中（后）序遍历 |
*注：如果不知道如何遍历，先转化为二叉树，再对二叉树进行相应的遍历*

# 考点6 哈夫曼树与哈夫曼编码

选择题考频：10/16年
大题考频：2/16年

哈夫曼树的相关**知识点**：（联想到计网中**变长子网划分**）
 1. 将n个字符出现的频率作为**权**构造一棵哈夫曼树，由哈夫曼树求得的编码就是==哈夫曼编码==
 2. 哈夫曼树的构造过程决定了字符一定是**叶子结点**
 3. 哈夫曼编码是前缀编码，不允许某个字符的编码是另一个的前缀，所以**两个字符不能出现再树中从根到某个叶子结点的同一路径上**

定长哈夫曼编码：所有字符都位于哈夫曼树的同一层，哈夫曼编码长度相同
变长哈夫曼编码：字符位于哈夫曼树的不同层，哈夫曼编码长度不同

哈夫曼树/编码的**规律**：
 1. 若有n个节点，则在哈夫曼树的构造过程中==新建了n-1个节点==，最终一共==2n-1个节点==
 2. 哈夫曼树==只有度为0和2的结点==，不存在度为1的结点，即$n=n_0+n_2$
 3. 非空二叉树满足$n_0=n_2+1$，所以哈夫曼树$n=2n_0-1=2n_2+1$
 4. 权值（频度）越小的结点一般离根节点**越远**，利用该性质保证出现最多的字符拥有最短编码
 5. 同一组权值构造出的哈夫曼树可能不唯一
 6. m叉哈夫曼树
     1. 定义：只有度为0和度为m的结点的哈夫曼树
     2. 构造过程：初始结点有$n_0$个，首先计算$k=(n_0-1)\mod(m-1)$，若$k\neq0$，则需要补充$m-1-k$个权值为0的结点
     3. 仿照二叉哈夫曼树的构造过程，每次结合m个权值最小的结点，重复该过程

==判定某字符集的不等长编码是否具有前缀特性==
- 核心思想：从根节点出发，按位依次为每个码字建树（0向左、1向右）。若某码字在插入过程中**整条路径的所有节点均已存在且未新建任何节点**，则说明该码字是某个已有码字的前缀（或与已有码字重复），不具备前缀特性
- 若插入过程中**途经任何已被标记为码字终点的叶子节点**，则说明该码字以某个已有码字为前缀，同样不具备前缀特性


## WPL的计算

WPL（带权路径长度）
 - **结点**的WPL：从该节点到根之间的路径长度 × 节点上权值
 - **树**的WPL：树中所有**叶子节点**的带权路径长度之和
