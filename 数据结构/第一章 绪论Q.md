## 求解时间复杂度

**求解时间复杂度**：
 1. 确定==基本运算==
 2. 找出==变化规律==
 3. 联系==跳出条件==

**例1（2011真题）**（单循环）：
```cpp
x = 2;
while(x < n/2)
	x = 2*x
```
此时时间复杂度，假设进行了t轮（t是满足条件的最后一次）

| t   | 1     | 2     | 3     | ... | t         |
| --- | ----- | ----- | ----- | --- | --------- |
| x   | $2^2$ | $2^3$ | $2^4$ | ... | $2^{t+1}$ |
∴ 有$2^{t+1}<n/2 \rightarrow t<\log_2n$
 - 其实可以将其联想到**归并排序**，归并排序递归，归的时候的趟数，时间复杂度为$\log_2n$

**例2**（递归）：搞清楚它如何调用
```cpp
int fact(int n){
	if(n <= 1)return 1;
	return n * fact(n-1);
}
```
解：直接找一个数进行找规律，即以5为例：`fact(5) -> 5*fact(4) -> 4*fact(3) -> 3*fact(2) -> 2*fact(1)`不难发现，一共进行了5次递归，而内部的每次时间复杂度为O(1)，所以总的时间复杂度为$O(1)\times n=O(n)$

**例3**（嵌套for循环）：
==层层无关==：直接内外侧相乘即可
```cpp
count = 0;
for(k=1;k<=n;k*=2){
	for(j=1;j<=n;j++){
		count++
	}
}
```
解：对于j，循环次数显然是n，而对于k，从==例1==易得时间复杂度为$O(\log_2n)$，即最终的时间复杂度为$O(n\log_2n)$

==层层制约==：
```cpp
int sum = 0;
for(int i=1;i<n;i*=2){
	for(int j=0;j<i;j++){
		sum++
	}
}
```
直接列表找规律：

| 轮次        | 1       | 2       | 3       | ... | ？   |
| --------- | ------- | ------- | ------- | --- | --- |
| i         | 1       | 2       | 4       | ... |     |
| j         | 0       | 0，1     | 0，1，2，3 | ... | ... |
| t（每轮执行次数） | $1=2^0$ | $2=2^1$ | $4=2^2$ | ... | ?   |
不难发现每轮执行次数t与i的值相等，而t构成一个等比数列，总的执行次数即为等比数列求和，而由==例1==可知，一共进行了$\log_2n$轮，所以最终一共执行了（*注：这里的计算没有那么精确，总轮次可能+1或-1，但计算时间复杂度并不需要那么精确*）
$$\frac{a(1-q^N)}{1-q}=\frac{2(1-2^{\log_2n})}{1-2}\approx O(n)$$

<mark>时刻知道，求解时间复杂度，关注的一直都是基本运算的执行次数</mark>
