	        - ==无符号数有意义==

	    - ZF
	        - 无符号数和有符号数均有意义
	        - 运算结果的机器数全为0，ZF=1

	    - 外存、内存、高速缓存、寄存器 -- 速度、容量、价格

	    - 主存    - 辅存层主要解决内存容量问题，虚拟存储

 - 主存储器
     - RAM
        - SRAM
        - DRAM
           -  刷新方式：集中刷新、分散刷新、异步刷新
           - DRAM芯片存储矩阵，行和列的概念 -- 行列地址复用，地址引脚减半
           - 刷新单位：按行刷新
        - 二者对比，==85页表格（27版）==
     - ROM
        - 掩模式只读存储器MROM -- 生产时写入，写入无法改变
        - 一次可编程只读存储器PROM -- 用户用专门的设备写入，写入无法改变
        - 可擦除可编程只读存储器 -- 可读可写，但写入次数有限，且写入时间过长
        - Flash存储器（闪存） -- 快速擦除与重写
        - 固态硬盘SSD（基于闪存） -- 相比机械硬盘读写速度更快
     - 多模块存储器
        - 单体多字存储器
        - 多体并行存储器
           - 高位交叉编址（顺序方式）：优先对一个模块编址，高位是模块号
           - 低位交叉编址（交叉方式）：各个模块交叉编址，低位是模块号
              - 轮流启动
                 - 存储器总线位数等于单个模块位数
                 - m体交叉编址存储
                 - 各模块轮流访问
                 - 同一个模块两次访问需要间隔一个存储周期
                 - 相邻模块间隔（存储周期/m）
                 - 一个存储周期各个模块轮流各访问一次
              - 同时启动
                 - 存储器总线位数等于各个模块位数之和
                 - 一个存储周期同时访问各个模块相同地址数据
 - 主存储器和CPU的连接
    - 位扩展 -- 8K\*1位 -> 8K\*8位 需8个芯片
    - 字扩展 -- 16K\*8位 -> 64K\*8位 需4个芯片
    - 字位同时扩展：16K\*4位 -> 64K\*8位 需8个芯片
    - 计算芯片扩展成指定规格所需芯片数量
    - 分析地址中的芯片号位数和芯片内地址位数
      求某个芯片最小地址与最大地址
 - 外部存储器
    - 磁盘存储器（*与操作系统5.3内容重叠，计组和操作系统大题均有考察*）

        - 基本概念：扇区、磁道、柱面、盘面
        - 磁盘存取时间
           - 寻道时间
           - 旋转延迟时间
           - 传输时间
        - 磁盘地址：柱面（磁道）号、盘面（磁头）号，扇区号
        - 磁盘阵列：RAID（独立冗余磁盘阵列）
    - 固态硬盘
 - <span style="color:red;font-weight:bold">高速缓冲存储器</span>
   考频高，综合性高，并且经常和操作系统第三章以及计组3.6综合考察选择题和大题
    - 局部性原理
        - 时间局部性和空间局部性的定义
        - 时间局部性：程序往往有大量循环
        - 空间局部性：指令和数据往往顺序存放
    - Cache基本概念
        - Cache块（行）、内存块
        - 根据物理地址计算内存块号和块内地址，块内地址的含义
        - 访问单位
           - CPU访问内存和Cache以**字**为单位
           - Cache和内存以**块**为单位交换数据
    - Cache映射方式
        - 直接映射、全相联、组相联映射 -- 以主存块为单位按照某种规则放入Cache块中
        - 各种映射方式的地址结构以及拆分原理
        - 直接映射中行号的计算
        - 组相联映射中组号的计算
    - Cache总容量
        - 数据：一般以**字节**为单位
        - 标记项：一般以**比特**为单位
           - 标记 -- 根据各种映射的地址结构分析，反映Cache块放的是哪个内存块

        - 若命中，最后根据块内地址访问Cache块中具体的某个数据

           - 组相联：路数
           - 全相联：行数
    - Cache中主存块的替换算法（直接映射不需要，而全相联和组相联需要）

        - 写命中，要修改的块在Cache中
           - 全写法
           - 回写法
        - 写不命中，要修改的块不在Cache中
           - 非写分配法
           - 写分配法
 - 虚拟存储器（==和操作系统第三章高度相关，必须先学操作系统第三章==）
    - 虚拟存储基本概念（==和操作系统3.2重叠==）

            - 变址寄存器内容改变，指令中的地址码不变
            - 采用专用寄存器，采用通用寄存器作为变址寄存器
            - 处理数组问题，数组首地址存放在指令地址码中

	    - 空间并行：设置多个功能部件，使多条指令可以同时执行同一个阶段，超标量处理机
    - **流水线的五个阶段**
	    - 取值IF
	    - 译码/读寄存器ID
	    - 执行/计算地址EX
	    - 访存MEM
	    - 写回WB
    - *流水线对指令集的要求*
    - *流水线的基本实现*
        - 流水线设计的原则
        - 流水线的逻辑结构
           - 注意其中流水段寄存器的用途
            - 用于锁存本段处理完的所有数据，以保证本段的执行结果能在下一个时钟周期给下一个流水段使用
    - 流水线的冒险与处理 -- 重点理解为何冲突以及如何解决冲突
        - 不同指令在各个流水段中的操作（==251页表格==）
           - 计算类：ALU
           - 取/存（LOAD/STORE）
           - 转移指令
              - 条件转移，MEM阶段更新PC
              - 无条件转移：EX阶段更新PC
        - 结构冒险/资源冲突
           - 原因：不同指令同一时刻使用同一功能部件
           - 解决
              - 推迟后续指令
              - 设置多个独立部件，数据Cache和指令Cache分离
        - 数据冒险/数据相关
           - 原因：后面指令需要读的寄存器，刚好是前面指令需要写回的寄存器
           - 解决
              - 延迟执行相关指令使得后续指令的ID发生在前面相关指令的WB之后
                 - 插入空操作nop指令
                 - 硬件阻塞
              - 采用转发（旁路）技术
                上条指令在EX阶段计算的结果直接转发到ALU的输入段
                下条指令的EX阶段直接拿来计算，无需从寄存器去读
              - load-use数据冒险
                 - 延迟加转发
                 - load指令在MEM阶段才取到数据
                   下条指令的EX需要在上条指令的MEM之后
        - 控制冒险/控制冲突
           - 原因：当前指令还未将PC去更新为转移后的目标地址，下条指令就开始执行
           - 解决
              - 推迟后续指令，使得下条指令的IF阶段发生在转移指令将PC更新之后
              - 对转移指令进行分支预测
    - 流水线的性能指标
       - k段流水线执行n条指令所需的时钟周期：k+n-1
       - 吞吐率：单位时间内流水线执行的指令数目
       - 加速比：不使用流水线与使用流水线所用的时间之比
    - 高级流水线技术
       - 超标量流水线技术
          - 配置多个功能部件
            多条指令完全并行
            CPI < 1，一个时钟可同时执行多条指令，每条指令平均所需时钟不到1个
          - 结合动态流水线调度技术，指令不按顺序执行，乱序执行
            会将无冒险的指令同时并发执行
