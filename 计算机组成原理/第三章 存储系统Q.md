**思维导图**：
 - 存储器概述
	- 存储器的分类
	    - 按作用层次 -- 主存、外存、高速缓存
	    - 按存取方式
	       - 随机存储器RAM、只读存储器ROM
	       - 串行访问存储器
	          - 顺序存取存储器（磁带）
	          - 直接存取存储器（磁盘、光盘）
	    - 按信息的可保存性 -- 易失性存储器
	- 存储器性能指标 -- 存储容量、存取时间、存取周期、主存带宽
	- 多级层次的存储系统
	    - 外存、内存、高速缓存、寄存器 -- 速度、容量、价格
	    - Cache - 主存层主要解决CPU和主存速度不匹配
	    - 主存    - 辅存层主要解决内存容量问题，虚拟存储
	    - Cache、主存能与CPU直接交换信息
	    - 辅存需要通过主存与CPU交换信息
 - 主存储器
     - RAM
        - SRAM
        - DRAM
           -  刷新方式：集中刷新、分散刷新、异步刷新
           - DRAM芯片存储矩阵，行和列的概念 -- 行列地址复用，地址引脚减半
           - 刷新单位：按行刷新
        - 二者对比，==85页表格（27版）==
     - ROM
        - 掩模式只读存储器MROM -- 生产时写入，写入无法改变
        - 一次可编程只读存储器PROM -- 用户用专门的设备写入，写入无法改变
        - 可擦除可编程只读存储器 -- 可读可写，但写入次数有限，且写入时间过长
        - Flash存储器（闪存） -- 快速擦除与重写
        - 固态硬盘SSD（基于闪存） -- 相比机械硬盘读写速度更快
     - 多模块存储器
        - 单体多字存储器
        - 多体并行存储器
           - 高位交叉编址（顺序方式）：优先对一个模块编址，高位是模块号
           - 低位交叉编址（交叉方式）：各个模块交叉编址，低位是模块号
              - 轮流启动
                 - 存储器总线位数等于**单个模块**位数
                 - m体交叉编址存储
                 - 各模块轮流访问
                 - 同一个模块两次访问需要间隔一个存储周期
                 - 相邻模块间隔（存储周期/m）
                 - 一个存储周期各个模块轮流各访问一次
              - 同时启动
                 - 存储器总线位数等于**各个模块**位数之和
                 - 一个存储周期同时访问各个模块相同地址数据
 - 主存储器和CPU的连接
    - 位扩展 -- 8K\*1位 -> 8K\*8位 需8个芯片
    - 字扩展 -- 16K\*8位 -> 64K\*8位 需4个芯片
    - 字位同时扩展：16K\*4位 -> 64K\*8位 需8个芯片
    - 计算芯片扩展成指定规格所需芯片数量
    - 分析地址中的芯片号位数和芯片内地址位数
      求某个芯片最小地址与最大地址
 - 外部存储器
    - 磁盘存储器（*与操作系统5.3内容重叠，计组和操作系统大题均有考察*）
        - 组成：磁盘驱动器、磁盘控制器、盘片
        - 基本概念：扇区、磁道、柱面、盘面
        - 磁盘存取时间
           - 寻道时间
           - 旋转延迟时间
           - 传输时间
        - 磁盘地址：柱面（磁道）号、盘面（磁头）号，扇区号
        - 磁盘阵列：RAID（独立冗余磁盘阵列）
    - 固态硬盘
 - <span style="color:red;font-weight:bold">高速缓冲存储器</span>
   考频高，综合性高，并且经常和操作系统第三章以及计组3.6综合考察选择题和大题
    - 局部性原理
        - 时间局部性和空间局部性的定义
        - 时间局部性：程序往往有大量循环
        - 空间局部性：指令和数据往往顺序存放
    - Cache基本概念
        - Cache块（行）、内存块
        - 根据物理地址计算内存块号和块内地址，块内地址的含义
        - 访问单位
           - CPU访问内存和Cache以**字**为单位
           - Cache和内存以**块**为单位交换数据
    - Cache映射方式
        - 直接映射、全相联、组相联映射 -- 以主存块为单位按照某种规则放入Cache块中
        - 各种映射方式的地址结构以及**拆分原理**
        - 直接映射中**行号**的计算
        - 组相联映射中**组号**的计算
    - Cache总容量
        - **数据**：一般以**字节**为单位
        - **标记项**：一般以**比特**为单位
           - 标记 -- 根据各种映射的地址结构分析，反映Cache块放的是哪个内存块
           - 有效位 -- 必有，占1位
           - 脏位（一致性维护位）
              - 回写：1位
              - 全写：0位
           - 替换算法位：常用LRU替换算法
              - 直接映射：不需要
              - 全相联：$\log_2行数$
              - 组相联：$\log_2路数$
    - Cache的访问流程/判断Cache是否命中，以组相联映射为例
        - 先看组号，确定对应数据在Cache的那一组
        - 当前访问物理地址的标记和Cache块的标记对比
          查看Cache中放的是否是想要访问的内存块
        - 再看有效位是否为1
        - 若命中，最后根据块内地址访问Cache块中具体的某个数据
          若缺失，将内存块调入对应的Cache块，并修改Cache块中的标记和有效位
    - Cache命中率、缺失率、命中次数、缺失次数的计算 
       -  一般根据单个Cache块分析，注意代码中每个数据的访问次数
    - 比较器的位数和个数
        - 位数等于标记的位数，根据映射方式求标记位数
        - 个数
           - 直接映射：1个
           - 组相联：路数
           - 全相联：行数
    - Cache中主存块的替换算法（直接映射不需要，而全相联和组相联需要）
        - 随机算法
        - 先进先出算法
        - **最久未使用算法LRU** -- ==该算法思想在操作系统3.2页面置换算法也有提及==
    - Cache写策略
        - 写命中，要修改的块在Cache中
           - 全写法
           - 回写法
        - 写不命中，要修改的块不在Cache中
           - 非写分配法
           - 写分配法

        - 请求分页流程
        - 虚拟地址的地址结构
        - 请求分页页表
        - 地址变换
    - 快表TLB：原理可结合Cache理解
        - 快表中存放经常用到的**页表项**
        - TLB中的内容：标记、有效位、页框号
        - 快表的映射方式及地址结构：全相联、组相联
        - TLB的地址变换流程，也是按照映射方式，类比Cache
    - 分页、快表TLB、Cache的综合理解 -- ==132、133页图的理解（27版）==
    - 快表TLB、页表Page、高速缓存Cache，三者命中和缺失的组合情况==133页表==
      快表命中说明必在内存
      页表命中说明必在内存，页表缺失说明必不在内存
      Cache命中说明数据必在内存，Cache放的就是内存的一部分
      但Cache缺失不能说明不在内存
        - TLB命中，Page一定命中，Cache是否命中都可以
        - Page缺失，TLB一定缺失，Cache一定缺失
        - Cache命中，Page一定命中
