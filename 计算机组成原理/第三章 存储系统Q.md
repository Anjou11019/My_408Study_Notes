# VA -> PA 总览
##### 9.30
![[图一上.png]]

![[图一下.png]]

VA -> PA
 1. 用虚拟页号查TLB
 2. 若TLB**命中**则直接得到页框号
 3. 若TLB**未命中**则需要查询慢表（内存）
 4. 通过查询慢表得到页框号
 5. 页框号 拼接 页内偏移量得到完整的==物理地址PA==
 6. 用物理地址访问**Cache**
     - 6以上均为**操作系统**内容
     - 6之后为**计算机组成原理**内容
 7. 若Cache**命中**，直接得到目标数据
 8. 若Cache**未命中**，则使用物理地址访问**主存**
 9. 从主存中得到目标数据
 10. 将数据送给CPU
      - 如果是 **指令**则通过MDR放入**IR**
      - 如果是 **数据**则通过MDR放入**某寄存器**中

**虚拟地址来源**：
 - 取指阶段：PC中存的是指令的VA
 - 执行阶段：可能来自指令的地址码（间接寻址->一次间接寻址中是VA）

CPU拿到虚拟地址 -> 拆分成虚拟页号 + 页内偏移量
 - 虚拟页号：拿去查TLB快表（硬件原理类似Cache）
 - CPU内部含有**MMU内存管理单元**，其功能即为==VA -> PA==

# Cache命题角度

**Cache考点**：
 - 六个注意的条件
    1. 物理地址PA位数
    2. Cache总行数
    3. Cache块大小
        - 2，3可以得出，Cache**数据区的大小**
    4. Cache-主存映射方式
        - 全相联映射
        - 组相联映射
           - K路组相联映射，意味着包含K个Cache行
           - <span style="color:red;font-weight:bold">组数 = Cache总行数 ÷ 路数</span>
           - 思考需要多少bit才能够表示Cache组号
        - 直接映射 -- 关注Cache总行数，思考多少bit才够表示行号
    5. 写策略
        - 直写write-through：写Cache的同时写内存
        - 写回write-back：需要占用一个脏位
    6. 替换算法：*只有全相联、组相联需要考虑替换算法*
        - 最近最久未使用LRU
        - 先进先出FIFO
        - 随机RAID
 - 命题角度1：分析访问某个PA时，Cache是否命中
    1. 先拆分物理地址PA：主要关注 ==④写策略==，确定地址结构
        - 全相联映射：PA = 【Tag，块内地址】
        - 组相联映射：PA = 【Tag，组号，块内地址】
        - 直接映射：PA = 【Tag，行号，块内地址】
    2. 在关注1，3，2，确定各个部分分别占多少bit
        - 直接映射：行号由 ==②Cache总行数==确定，块内地址由==③Cache块大小==确定
        - 组相联映射：块内地址由③确定，组号由==组数 = $\dfrac{总行数}{路数}$==确定
        - 全相联映射：块内地址由③确定
 - 命题角度2：分析一个Cache行的完整构成（*④⑤可能不存在，结合题目分析*）
    1. ==Tag标记位==
        - 判断Tag占多少bit
        - 关注==注意的条件中的1，2，3，4点==
    2. ==V有效位==
        - 一定存在，占1bit
    3. ==块内数据==
        - 关注==注意的条件中的3==
           - 通常题目会直接告诉块内数据多大
           - 也可能通过块内地址推出块内数据的大小
    4. 替换信息
        - 判断替换信息占多少bit？
        - 关注==注意的条件4，6==
           - 若采用**直接映射**方式，则替换信息==位数 = 0bit==
           - 若采用**组相联映射**方式
              - 采用**随机替换**算法，则替换信息==占0bit==
              - 采用**LRU**或**FIFO**算法，则替换信息==位数 = $\log_2路数$==
           - 若采用**全相联映射**方式
              - 采用**随机替换**算法，则替换信息==占0bit==
              - 采用**LRU**或**FIFO**算法，则替换信息==位数 = $\log_2总行数$==
    5. 脏位 关注==注意的条件⑤==
        - 直写法，不需要设置脏位
        - 写回法，需要设置1bit脏位

## 知识点

$VA\xRightarrow[未命中查慢表]{查TLB} PA\Rightarrow Cache A$
 - VA -> （**虚页号VPN**，页内地址）
    - VPN查TLB：
       - 全相联映射：整个VPN作为标记
       - 组相联映射：VPN被拆为【TLB标记，TLB组号】
 - PA -> （**页框号**，页内地址）
 - Cache：
    - 全相联映射：【标记，块内地址】
    - 组相联映射：【标记，组号，块内地址】
    - 直接映射：【标记，行号，块内地址】

==Cache总容量 v.s. Cache数据区==
 - Cache总容量：含块，Tag，有效位，替换位，脏位
 - Cache数据区：块的大小

        - 组相联映射
           - N路组相联，意味着每组可存N个页表项
           - <span style="color:red;font-weight:bold">组数 = TLB页表项总数 ÷ 路数</span>
           - 思考需要多少个bit才能够表示TLB“组号”
        - 直接映射（这种方式一般不用于TLB）
 - 常见命题角度1：<span style="color:red;font-weight:bold">根据VA分析TLB是否命中</span>
    - 步骤1：用虚页号查TLB，根据TLB不同的映射方式，将虚页号拆分
    - 映射方式
       - 全相联：Tag
          - Tag位数与虚页号相同
       - 组相联：Tag+组号
          - 组号位数与TLB组数相同，$TLB组数=\dfrac{TLB表项总数}{路数}$
       - 直接：Tag+行号
          - 行号与TLB表项总数相关
    - 步骤2：根据映射方式不同，按步骤分析查TLB的过程
       - 组相联映射
          - 先根据组号找到对应分组
          - 再和分组中的N个TLB表项对比Tag
          - 如果Tag匹配、且有效位=1，则TLB命中
       - 全相联映射
          - 直接用虚页号对比每一个TLB页表项的Tag，
          - 如果Tag匹配，且有效位=1，则TLB命中
 - 常见命题角度2：<span style="color:red;font-weight:bold">分析TLB表项的完整构成</span>
    - Tag标记位：具体多少位取决于虚拟页号的位数、TLB映射方式
    - 有效位：1bit，**一定存在**
    - 页框号：与内存的物理页框数量有关
    - 替换信息
       - 用于淘汰TLB，取决于TLB替换算法
       - 全相联映射：替换信息位的位数取决于TLB表项总数
       - 组相联映射：替换信息位的位数取决于每个分组中TLB表项总数

## 选择题
正确率：83/112 = 74%（其中概念题：21/22，考点题：62/90）
其中真题正确率：25/34

**知识点**：
1. 某存储芯片，动态刷新间隔为2ms，读写周期及刷新周期均为0.5μs，该芯片包含128行，每个刷新周期完成1行存储单元的刷新，若芯片采用<span style="color:red;font-weight:bold">异步刷新</span>方式工作，那么其读写周期和刷新周期可以安排为？
    - 异步刷新：将刷新周期除以行数，得到两次刷新的时间间隔t，则2ms内读写和刷新的总次数 = 2ms/0.5μs = 4000，其中刷新共128次，读写3872次，由于是异步刷新，所以<span style="color:red;font-weight:bold">读写 ： 刷新 = 3872 ：128 ≈ 30 ： 1</span>
2. 上述问题，若改为<span style="color:red;font-weight:bold">集中刷新</span>，那么其读写周期和刷新周期安排为？
    - 集中刷新：利用固定时间，依次对存储器逐行进行刷新，2ms内读写和刷新的总次数 = 2ms/0.5μs = 4000，即每过3872个读写周期，就集中进行128次刷新
3. SDRAM同样是DRAM的一种，同样需要进行刷新
4. 某SRAM容量为1024×8位，除接地和电源端之外，该芯片地址和数据引脚至少是？
    - 寻址范围$1024 = 2^{10}$，即地址线10根，数据线8根，共计18根
    - *若将题目改为**DRAM**，由于有地址复用技术，所以只需13根*
5. 某DRAM采用地址复用技术，容量为1MB，按字节编址，除接地和电源端之外，该芯片引脚至少是？（读/写 控制线两根）
    - 按字节编址，即需要**8根数据线**，$1M = 2^{20}$，又采用地址复用技术，共计**10根地址线**，行选通和列选通2根，读写控制线2根，==共计10 + 8 + 2 + 2 = 22根==
6. 设8个模块组成的多模块存储器，采用**地位交叉编址**，每个模块的存储字长为32位，存取周期为240ns，当连续读取16个存储字的时候，数据传输速率约为？
7. `for(i=0;i<1000;i++)a[i] = a[i] + 32`，若a与i均为int型，int型占4B，Cache采用直接映射，数据区大小1K，块大小16B，执行前Cache为空，则该程序的执行过程中Cache的缺失率为？
    - 一个块内可存4个元素，而`a[i] = a[i] + 32`需要对`a[i]`进行1次读及1次写操作，但每4个元素的8次读写，仅有第一次的读Cache会未命中，即==缺失率为1/8=12.5%==
8. 对于Cache比较器的个数和位数：
    1. 比较器的位数 = 标记位的位数，而==标记位位数 = 主存地址位数 - 组号位数 - 块内偏移位数==
    2. r路组相联映射下，比较器的个数 = r个
9. 采用指令Cache与数据Cache分离的主要目的是==**减少指令流水线资源冲突**==
    1. 在指令流水线中，如果指令和数据存放在同一个Cache中可能会出现，可能会出现指令预取和数据访问同时竞争Cache资源的情况，导致流水线阻塞
10. 指令Cache访问的空间局部性通常优于数据访问
11. 缺页知识点：
	1. 若对应页表项的有效位为0，则发生缺页
	2. 缺页处理的过程中需要根据页表中给出的磁盘地址去读磁盘数据
	3. 缺页是一种外部中断，需要调用操作系统提供的中断服务程序来处理
	4. 缺页处理完成后，需要重新执行发生缺页的指令
