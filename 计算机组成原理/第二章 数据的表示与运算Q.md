# 整数的表示与类型转换

##### 9.17

## n bit整数表示范围

**范围**：
 - 无符号整数：$0\sim 2^n-1$
 - 带符号整数（补码）：$-2^{n-1}\sim 2^{n-1}-1$（==负数多一个==）

*手算的原理：先手算求数学真值，再检查是否超出相对应类型的表示范围*
 - **带符号整数**：
    - 溢出 OF=1
    - SF：正数&零=0 / 负数=1
    - ZF：如果是零=1
    - CF：==不能使用手算的方式逆推==
 - **无符号整数**：
    - SF：没有意义
    - CF：溢出=1
    - ZF：如果是零=1
    - OF：不能猜
## 补码快速转原码

**补码转原码**：
 1. 符号位为0：补码与原码相同，直接解释真值
 2. 符号位为1：从右到左找到第一个1，==该位及其**右边**保持不变==，它左边的所有数值位取反，符号位保持为1
 - **特别的**：补码$10...0$表示$-2^{n-1}$，无法转换成同位宽原码，直接写真值

## <span style="color:red;font-weight:bold">不同类型整数变量之间转化，位宽和类型变化</span>

一句话总结：==先按照“原有符号性”完成拓展/截断，再按照“目的符号性”解释==
 - 同宽转换：位串不变，只改变解释方式
 - 位宽变大
    - **原数是带符号数**：先符号扩展（复制符号位），再按目的类型解释
    - **原数是无符号数**：先零拓展（高位补0），再按目的类型解释
 - 位宽变小：截断，只保留低位，再按目的类型解释

### 练习1（几乎包含全情况）

*考研一般情况`short unsigned short`为16位，`int unsigned int`为32位*
```cpp

// IV  位宽变大（16-32）、类型也变（带符号/无符号互转）

//FF86H 零扩展-> 0000 FF86H 按带符号数解释为65414
int p = q; //无符号->带符号

// V   位宽变小（32-16）、类型也变（带符号/无符号互转）
```

## 浮点数结构与真值

**float**：32位单精度浮点数，==float阶码偏置值127==

| 1 bit | 8 bit | 23 bit |
| ----- | ----- | ------ |
| 符号s   | 阶码e   | 尾数f    |
**偏置值**：先按照无符号整数的规则解读**阶码**，在其基础上**减去127**
 - 即**阶码e**的取值范围为1~254（全0和全1有其他用途）

**尾数**：23位尾数实际上表示了24位位有效数字，*因为第一位恒为1，所以隐藏*

<span style="color:red;font-weight:bold">IEEE 754标准的规格化单精度浮点数的真值为：</span>
$$
(-1)^s\times1.f\times 2^{e-127}
$$

非规格化浮点数的真值：
$$
(-1)^s\times0.f\times 2^{-126}
$$
**重要边界**：
$$
\begin{gather*}
最小正非规格化数 = 2^{-149}\\\\
最小正规格化正数 = 2^{-126}\\\\
最大有限正数 = (2-2^{-23})2^{127}
\end{gather*}
$$

## 编码与解码

**编码**（十进制真值转浮点数）：确定符号 -> 绝对值转二进制 -> 写成$1.F\times2^e$ -> 求$E=e+127$ -> 去掉隐藏位得到F -> 拼接S E F

**例如**：将十进制-8.25转化为IEEE 754单精度浮点数格式表示：
 - 先将-8.25转化为二进制，即$-1000.01 = -1.00001\times 2^3$，，尾数部分取小数点后23位，即$00001$后补0至23位
 - 再计算解码E，$E-127=3,E=130$，转化为二进制为$1000,\,0010$ 
 - IEEE 754单精度浮点数格式：S+E+F，即
$$
1,\,1000\,\,0010,\,0000\,\,1000\,\,0000\,\,0000\,\,0000\,\,000=C1040000H
$$
---

**解码**（二进制浮点数转十进制真值）：拆分S E F -> 判断编码类别(规格/非规格/特殊值) -> 恢复$1.F或者0.F$ -> 求真实阶指数 -> 计算真值

**例如**：求IEEE 754单精度浮点数$C640\,0000H$
 - 先将$C640\,\,0000H$ 按二进制展开
   $$
	   1100\,\,0110\,\,0100\,\,0000\,\,0000\,\,0000\,\,0000\,\,0000
   $$
 - 按照IEEE 754单精度浮点数格式划分
   |$S=1$|$E=1000\,\,1100$|$F=100\,\,0000\,\,0000\,\,0000\,\,0000\,\,0000$|
 - 因此S=1表示为负数，**阶码真值**为$1000\,\,1100-0111\,\,1111=(0000\,\,1101)_2=13$，**尾数真值**为$1+(0.1)_2=1.5$，因此该单精度浮点数的值为$-1.5\times 2^{13}$

## 注意真值用浮点数能否精确表示：检查精度

判断十进制有理数转化成二进制小数后，能否在有限位后结束，技巧如下：
 - 先把真值写成**最简分数**
 - 分母**只能**由若干个2相乘得到，二进制小数才能有限得到
 - 分母含3、5、7等其他因子，二进制小数会无限循环

| 数值              | 最简分数及分母                  | 结论      |
| --------------- | ------------------------ | ------- |
| 0.125           | $\dfrac{1}{8},8=2^3$     | 二进制有限   |
| 0.75            | $\dfrac{3}{4},4=2^2$     | 二进制有限   |
| 0.2             | $\dfrac{1}{5}$，含由因子5     | 二进制无限循环 |
| 0.3             | $\dfrac{3}{10},2\times5$ | 二进制无限循环 |
| $\dfrac{3}{12}$ | $\dfrac{1}{4}$           | 二进制有限   |
*一句话总结：==确定真值的二进制能够有限位结束后，还要检查有效数字是否能装入float的24位有效精度==*，例如：$2^{24}+1$不能精确表示，但$2^{24}+2$可以
