 - 文件系统基础
    - 文件的基本概念：
       - 文件的属性：名称、类型、创建者、大小、访问权限等
    - 文件控制块FCB
       - 管理文件，记录文件的各种属性：基本信息、存取控制信息、使用信息
       - 一个文件具有一个目录项，多个目录项会组成一个特殊的文件，叫==目录文件==
    - 索引节点
       - 有的系统采用文件名和文件描述信息分离，使得文件描述信息单独形成一个称为索引节点的数据结构
       - 不考虑特殊情况，一个文件具有一个索引节点，通过索引节点的个数来计算文件数量
       - 采用索引节点方式后，文件目录的每个目录项仅由文件名和相应的索引节点号组成
       - **磁盘索引节点**：放在==外存==，每个文件有一个唯一的磁盘索引节点
        包含：文件类型、文件存取权限、文件物理地址、文件链接计数
       - **内存索引节点**  ：放在==内存==，文件打开时，将磁盘索引节点复制到内存
        内存索引节点会增加一些内容：索引节点号，访问计数 
    - *到底文件的描述信息是放在FCB还是索引节点，需结合题目信息*、
    - 文件的操作：创建、删除、打开、关闭、读、写
       - open()：将文件对应的目录项从外存复制到内存，并将文件描述返回给用户
       - open()需要使用文件名，返回文件描述符，随后对于文件的其他操作如read()、write()、close()均使用文件描述符对文件进行操作
       - 多个进程打开同一文件
          - 系统打开文件表：
            通过打开计数器记录多少进程打开了同一个文件
          - 进程打开文件表：
            读写指针：对于进程而言是唯一的
            访问权限：只读，读/写等，保存在进程的打开文件表中
    - 文件的逻辑结构
    - <span style="color:red;font-weight:bold">文件的物理结构</span>
      结合优缺点理解概念，大题考频高
       - 磁盘的存储单元被分为一个一个的==磁盘块==，内存和磁盘之间的数据交换都是以磁盘块为单位，大小通常与内存页面大小相同
        多个盘块可以组成一个==簇==，若题目提到这个概念，则给文件分配空间时就会==按簇==分配
       - 描述一个文件占用的磁盘块在外存是如何分布和组织的，以及如何来记录一个文件占用了哪些磁盘块
       - 直接访问：访问一个文件的第i个块，**无需访问**该文件的前i-1个块
        顺序访问：访问一个文件的第i个块，**需访问**该文件的前i-1个块
       - **连续分配**
          - 类似数组，一个文件占用的磁盘块空间连续
          - 需要记录起始块号和块数，或者起始块号和结束块号
          - **优点**：支持直接访问
          - **缺点**：一个文件必须连续存放，文件动态增长不便，可能覆盖后续文件，删除和插入时磁盘块中的数据需移动
       - **链接分配**
         - **隐式链接**
            - 类似链表，每个盘块需要存放下一个盘块的指针
            - 指针位数需要根据整个磁盘空间的块数确定
            - 需要记录起始块号，类似头指针
            - **优点**：文件占用的磁盘块可以离散存放，无需事先知道文件大小，文件的插入删除也很方便
            - **缺点**：只支持顺序访问，指针出问题会导致后续数据丢失，指针的存放也需要空间
         - **显式链接**
            - 文件分配表FAT，每个表项存放下一个盘块的指针，整个文件系统只设置一张，还可以管理磁盘空闲空间
            - FAT表每个表项的位数根据整个磁盘空间的块数来确定
              FAT表表项的个数也是根据整个磁盘空间的块数来确定
            - 需要记录起始块号即可
            - *区分FAT表的大小与所表示文件大小的区别：类似于页表的大小与其所代表的整个进程页面大小的区别*
            - **优点**：支持直接访问
            - **缺点**：FAT需一直占用一定的空间
         - **索引分配**
            - 为每个文件分配一个索引块，存放该文件所有的盘块号
            - **优点**：支持直接访问
            - **缺点**：索引块增加了额外的存储空间开销
            - **直接索引**：地址指向存放文件数据的磁盘块
            - 一级索引：地址指向索引块，索引块中的每个地址指向存放文件数据的磁盘块
            - 二级索引：地址指向主索引块，主索引块中的每个地址继续指向第二级索引块，随后第二级索引块中的每个地址指向存放文件数据的磁盘块
            - 混合索引

               - 求单个文件最大长度
               - 求访问文件的某个数据位于几级索引，再计算需要访问的磁盘次数
    - 文件保护 -- 访问控制列表。规定每个用户及其允许的访问类型，通过矩阵的形式记录每类用户是否具有的某种权限

# 操作系统引导

逻辑格式化中，确定文件系统格式：UFS（**混合索引**，UNIX）、FAT（**显式链接**，早期Windows）

操作系统引导：
 1. CPU从一个特定主存地址开始，取指令，执行ROM中的引导程序（先进行硬件自检，再开机）
     - CPU -> ROM(BIOS)：包含ROM引导程序，即**自举程序**
 2. 将磁盘的第一块 -- 主引导记录读入内存，执行磁盘引导程序，扫描分区表
     - 主引导记录MBR（磁盘）：包含磁盘引导程序和分区表
 3. 从活动分区（又叫主分区，即安装了操作系统的分区）读入分区引导记录，执行其中的程序
     - 引导记录PBR（C盘）：负责找到启动管理器
 4. 从根目录下找到完整的操作系统初始化程序并执行，完成开机的一系列动作
     - 根目录（C盘）

# 磁盘初始化

磁盘初始化：
 1. 进行**低级格式化（物理格式化）**
     - 将磁盘的各个磁道**划分为扇区**，一个扇区可分为**头、数据区域、尾**三个部分组成。管理扇区所需的各种数据结构一般存放在头、尾两个部分，包括扇区校验码（如奇偶校验、CRC循环冗余校验等，校验码通常用于校验扇区中的数据是否发生错误）
 2. 将磁盘**分区**
     - 每个扇区由若干柱面组成
 3. 进行**逻辑格式化**
     - 创建文件系统，包括文件系统的根目录、初始化存储空间管理所用的数据结构
