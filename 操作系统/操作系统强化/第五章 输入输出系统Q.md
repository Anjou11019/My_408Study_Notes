# 开机过程

##### 10.26

**逻辑格式化**中，确定文件系统格式：UFS（混合索引，UNIX）、FAT（显式链接，早期Windows）

操作系统引导：
 1. CPU从一个特定主存地址开始，取指令，执行ROM中的引导程序（先进行硬件自检，再开机）
     - CPU -> ROM(BIOS)：包含ROM引导程序，即**自举程序**
 2. 将磁盘的第一块 -- 主引导记录读入内存，执行磁盘引导程序，扫描分区表
     - 主引导记录MBR（磁盘）：包含磁盘引导程序和分区表
 3. 从活动分区（又叫主分区，即安装了操作系统的分区）读入分区引导记录，执行其中的程序
     - 引导记录PBR（C盘）：负责找到启动管理器
 4. 从根目录下找到完整的操作系统初始化程序并执行，完成开机的一系列动作
     - 根目录（C盘）

磁盘初始化：
 1. 进行**低级格式化（物理格式化）**
     - 将磁盘的各个磁道**划分为扇区**，一个扇区可分为**头、数据区域、尾**三个部分组成。管理扇区所需的各种数据结构一般存放在头、尾两个部分，包括扇区校验码（如奇偶校验、CRC循环冗余校验等，校验码通常用于校验扇区中的数据是否发生错误）
 2. 将磁盘**分区**
     - 每个扇区由若干柱面组成
 3. 进行**逻辑格式化**
     - 创建文件系统，包括文件系统的根目录、初始化存储空间管理所用的数据结构

# IO层次

从上至下依次是：
 - 用户层软件
    - C语言库函数，比如stdio.h，会建立一个用户缓冲区（char buf[]）
 - 设备独立性软件
 - 设备驱动程序
 - 中断处理程序
 - 硬件

```c
main(){
	int x;
	scanf("%d",&x);
	printf("x = %d \n",x);
}
```

`scanf()`属于用户层软件 $\xRightarrow{read系统调用}$设备独立性软件 
 - 会陷入操作系统**内核**，开始执行操作系统的代码
设备独立性软件：缓冲区管理 -> 内核缓冲区：接收键盘输入

## IO控制器

CPU -> IO控制器 <- 键盘（假设输入1，2，3，4）
 - 假设1对应的二进制编码是00101101

**IO控制器**：
 - IO端口（寄存器）
    - 数据寄存器
    - 状态寄存器
    - 控制寄存器

键盘输入1 $\xRightarrow{00101101}$ 数据寄存器 $\xRightarrow{数据达到的中断信号}$CPU$\xRightarrow{根据中断类型}$中断处理程序$\xRightarrow{调用}$键盘驱动程序$\Rightarrow$引导CPU将数据取入（比如eax寄存器）$\xRightarrow{驱动程序}$将键盘厂商编码转换成ASCII编码

## printf

printf属于**用户层软件**，`printf("x=%d\n",x)`其会把1234字符串**格式化**

而后进入**内核**：write系统调用（写到设备：显示器）

**设备独立性软件**：将用户区的数据迁移进**内核输出缓冲区**

然后由操作系统完成从内核缓冲区到显示器的映射

IO控制器 $\Leftrightarrow$ 显示器
 - IO控制器：将内核缓冲区中的数据读入显存（**驱动程序**）

**知识点**：
 1. 用户通过键盘登录系统的时候，首先获得键盘输入信息的是**中断处理程序**
 2. IO核心子系统提供的服务主要有：==IO调度、缓冲与高速缓存、设备分配与回收、假脱机、设备保护和差错处理==
 3. 为用户进程分配设备的过程：先分配设备，再分配控制器，最后分配通道
 4. 为提高磁盘的读取速率，应将一个数据文件放在**统一柱面**
 5. 执行一次磁盘IO操作花费的时间为==寻道时间+延迟时间+传输时间==
 6. FCFS算法**不会**导致磁头臂黏着
